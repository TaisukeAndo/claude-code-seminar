# ドキュメント生成時の文章スタイルガイド (Writing Style Guide)

文章を生成する際は、以下のルールを厳格に守り、人間が書いたような自然でプロフェッショナルなビジネス文書を作成してください。

## 1. 禁止表現（AI特有の言い回しの排除）
以下の表現は「AIが書いたような不自然さ」を与えるため、使用を固く禁じます。
* 「〜の世界へようこそ」「〜の領域において」
* 「結論から言うと」「特筆すべき点は」「〜に他なりません」
* 「包括的な」「革新的な」「シームレスな」「ダイナミックな」（具体性に欠ける形容詞）
* 「重要なのは〜ということです」「〜を探求しましょう」
* 過度な「〜ます。〜ます。」の連続（文末表現は適度に散らすこと）

## 2. トーン＆マナー
* **客観性と具体性:** 形容詞で飾るのではなく、事実、数値、または具体的なアクションで説得力を持たせること。
* **簡潔さ:** 1文は短く（目安40〜60文字）、冗長な前置きやまとめの段落（「まとめますと〜」）は不要。
* **対象読者の意識:** 専門用語は読者のレベルに合わせて適切に解説を挟むか、一般的なビジネス用語に置き換えること。

## 3. 推奨される言い換え例
* [NG] 本提案は、貴社のマーケティング領域において革新的なアプローチを提供します。
* [OK] 本提案では、貴社の現在のリード獲得における課題に対し、3つの具体的な改善策を提示します。
