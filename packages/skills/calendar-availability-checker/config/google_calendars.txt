# calendar-availability-checker 対象Googleカレンダー設定
#
# 1行に1カレンダーID（通常はGoogleアカウントのメールアドレス）を記載する。
# 「#」で始まる行と空行は読み飛ばされる。
# ここに登録したカレンダーは、実行のたびに聞き直さずすべて自動でまとめてチェックする
# （複数のGoogleアカウント・複数のカレンダーを横断してチェックしたい場合は、
#  1行ずつ追加すればよい。詳しくはSKILL.mdの「Step 1: 対象カレンダーを決める」を参照）。
#
# 記入例（自分のメールアドレスに置き換えて、先頭の # を外す）:
# your-name@gmail.com
# your-team-account@gmail.com
