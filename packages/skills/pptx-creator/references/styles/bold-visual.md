# スタイルガイド：ビジュアルインパクト（Bold Visual）

## カラーパレット

| ロール | カラーコード | 用途 |
|--------|-------------|------|
| Primary | #0F172A | 背景・タイトル |
| Secondary | #1E293B | Section背景 |
| Accent | #6366F1 | 強調色・グラフメイン（インディゴ） |
| Accent2 | #F59E0B | 補助強調色（アンバー） |
| Background | #FFFFFF | 通常スライド背景 |
| Text | #0F172A | 本文テキスト |
| Dim | #64748B | サブテキスト |

## タイポグラフィ

| 要素 | フォント | サイズ | スタイル |
|------|---------|--------|---------|
| タイトルスライド見出し | Meiryo | 42pt | Bold |
| スライドヘッダータイトル | Meiryo | 24pt | Bold / 白 |
| セクションタイトル | Meiryo | 44pt | Bold / 白 |
| 本文 Level 0 | Meiryo | 20pt | Bold / Primary色 |
| 本文 Level 1 | Meiryo | 15pt | Regular / Dim色 |
| Stat 値 | Meiryo | 64pt | Bold / Accent色 |

## デザイン原則

1. 1枚のスライドに伝えることは1つだけ
2. 文字は少なく、インパクトを大きく
3. 数値・統計は必ず stat または chart スライドで視覚化する
4. セクション間のコントラストを強くして「次の話題」を明確に示す

## 適した用途

- 外部カンファレンス登壇
- Keynote 的な全体発表
- 新製品・新サービスの紹介
- 社外向けブランドプレゼン
