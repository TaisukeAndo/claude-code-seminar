## 2.14. 普段の PowerPoint 作成を話し合う

**時間: 5 分**

::: info グループワーク
近くの参加者と話し合ってください。  
全部話しきれなくても構いません。気になるテーマから話し始めてください。
:::

**テーマ 1：どんなスライド資料をよく作りますか？**

仕事の中で作るスライドの種類と、主な読み手・使う場面を共有してください。

**テーマ 2：どんなフローでスライドを作っていますか？**

「何から始めるか」「どの順番で作業を進めるか」など、普段の手順を話し合ってください。

| 作り方の例 | 特徴 |
|---|---|
| PowerPoint を直接開いて作り始める | すぐに着手できる |
| まず紙やメモにアウトラインを書く | 構成が固まってから作業できる |
| テンプレートをコピーして編集する | デザインが統一される |
| Word や Markdown で内容をまとめてからスライドに落とす | 内容と見た目を分けて考えられる |

**テーマ 3：1 本のスライドを作るのにどれくらい時間がかかりますか？**

スライドの枚数・種類ごとに、作成にかかる時間の目安を共有してください。  
特に「ここに時間がかかる」と感じる工程があれば話し合ってみてください。

## 2.15. 自分のスライド作成フローを書き出す

**時間: 4 分**

以下の質問に答えながら、自分がスライドを作るときの流れを書き出してください。

### 質問 1：どんなスライドをよく作りますか？

作成頻度が高いスライドを 2〜3 個書き出してください。

```
（記入例）
・クライアント向けの提案プレゼン
・社内の月次報告スライド
・勉強会・セミナー用の説明資料
```

### 質問 2：スライド 1 枚を作るまでに何をしていますか？

以下を参考に、自分の手順を書き出してください。

- 伝えたい内容を文章やメモで整理する
- 画像・グラフ・データを探す
- デザインのテンプレートを選ぶ または 一から作る
- テキストを入力してレイアウトを整える
- 完成後に誰かに確認してもらう

### 質問 3：スライド作成で最も時間がかかる作業はどこですか？

```
（記入例）
・伝わりやすい図や表を作るのに時間がかかる
・必要な画像・数値を探してくるのに時間がかかる
・デザインのバランスを整えるのに時間がかかる
```
