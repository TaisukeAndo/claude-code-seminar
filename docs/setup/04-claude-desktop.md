# 4. Claude Desktop のインストール

Claude Desktop は Anthropic 公式のデスクトップアプリです。  
最近のアップデートにより、**Claude Desktop から直接 Claude Code を利用できる**ようになりました。

## ダウンロード・インストール

1. [https://claude.ai/download](https://claude.ai/download) にアクセス
2. お使いの OS 用インストーラーをダウンロード
3. インストーラーを実行

| OS | ファイル形式 |
|---|---|
| macOS | `.dmg` ファイル → Applications フォルダにドラッグ |
| Windows | `.exe` インストーラー → 指示に従って進める |

---

## Claude Desktop で Claude Code を使う

インストール後、Claude Desktop を起動して Claude Pro アカウントでログインすると、チャット画面から Claude Code の機能を呼び出せます。

::: info Claude Desktop と Claude Code CLI の違い
- **Claude Desktop** — GUI アプリ。チャット形式で Claude Code を操作できる
- **Claude Code CLI** — ターミナルで動作。より細かい操作やスクリプトとの連携が得意

セミナーでは主に CLI を使いますが、Claude Desktop も便利なツールとして活用できます。
:::
