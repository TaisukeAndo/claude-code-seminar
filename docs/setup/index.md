# セットアップの全体像

セミナー開始前に以下の 5 ステップを完了してください。  
**所要時間の目安: 約 30 分**

## チェックリスト

- [ ] **ステップ①** [動作環境の確認](/setup/01-requirements) — macOS / Windows の要件チェック
- [ ] **ステップ②** [Node.js インストール](/setup/02-nodejs-install) — v18 以上が必要
- [ ] **ステップ③** [Claude Code CLI インストール](/setup/03-claude-code-install) — `npm install -g @anthropic-ai/claude-code`
- [ ] **ステップ④** [API キーの取得・設定](/setup/04-api-key) — Anthropic Console でキーを取得
- [ ] **ステップ⑤** [動作確認](/setup/05-verify) — `claude --version` が表示されれば完了

## セットアップの流れ

```
動作環境確認 → Node.js インストール → Claude Code インストール → API キー設定 → 動作確認
     ①               ②                      ③                    ④             ⑤
```

## 困ったときは

途中でつまずいたら [よくある質問](/faq) を確認してください。  
解決しない場合はセミナー当日に講師にお声がけください。
