# 3. テキストエディタのインストール

Claude Code はターミナルから操作しますが、コードを確認・編集するためにテキストエディタも準備しておきましょう。

## おすすめのエディタ

### Cursor（AI 機能に強い・推奨）

Cursor は VS Code をベースに AI 機能を強化したエディタです。Claude Code との組み合わせで特に威力を発揮します。

1. [https://www.cursor.com/](https://www.cursor.com/) にアクセス
2. **「Download」** をクリックして自分の OS 用をダウンロード
3. インストーラーを実行

---

### Visual Studio Code

Microsoft 製の定番エディタです。豊富な拡張機能があり、Claude Code の IDE 統合にも対応しています。

1. [https://code.visualstudio.com/](https://code.visualstudio.com/) にアクセス
2. **「Download for ...」** をクリックしてダウンロード
3. インストーラーを実行

::: tip VS Code で Claude Code を使う
VS Code に **Claude Code 拡張機能** をインストールすると、エディタ内から Claude Code を操作できます。  
拡張機能マーケットプレイスで「Claude Code」と検索してインストールしてください。
:::

---

### その他のエディタ

- **Windsurf** — AI コーディングに特化したエディタ
- **Zed** — 高速動作で知られる軽量エディタ

いずれも Claude Code はターミナルで動作するため、お好みのエディタを使っていただいて問題ありません。
