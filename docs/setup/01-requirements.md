# ① 動作環境の確認

セミナーで使用する Claude Code CLI の動作に必要な環境を確認します。

## 対応 OS

| OS | 対応バージョン |
|---|---|
| macOS | 12 Monterey 以降 |
| Windows | Windows 10 / 11（64bit） |
| Linux | Ubuntu 20.04 以降など |

## 必要スペック

| 項目 | 最低要件 | 推奨 |
|---|---|---|
| CPU | デュアルコア 1.8GHz 以上 | クアッドコア以上 |
| メモリ | 4GB | 8GB 以上 |
| ストレージ | 1GB 以上の空き容量 | — |
| ネットワーク | インターネット接続必須 | — |

## 事前に確認しておくこと

### ターミナル（コマンドプロンプト）が使えること

- **macOS**: `ターミナル.app`（Spotlight で "terminal" と検索）
- **Windows**: `PowerShell` または `コマンドプロンプト`（Win + X → PowerShell を選択）

### インターネット接続

Claude Code は Anthropic の API に接続するため、**インターネット接続が必須**です。  
セミナー会場の Wi-Fi 接続を事前に確認しておいてください。

## 次のステップ

環境の確認ができたら [② Node.js インストール](/setup/02-nodejs-install) に進んでください。
