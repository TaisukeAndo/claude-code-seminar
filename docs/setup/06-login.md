# 6. Claude Pro でログイン

Claude Code は **Claude Pro プランに加入**していれば、API キーなしで無制限に利用できます。  
ブラウザを使った認証で、**Google アカウントまたはメールアドレス**でログインします。

## 事前確認：Claude Pro への加入

**[https://claude.ai/](https://claude.ai/)** にアクセスして、Pro プランに加入していることを確認してください。

::: info まだ Pro に加入していない場合
1. [https://claude.ai/](https://claude.ai/) にアクセス
2. 右上の「Upgrade to Pro」または「プランを変更」をクリック
3. Pro プランを選択してお支払い情報を入力

月額料金（約 $20）がかかりますが、セミナー中に追加費用（API 従量課金）は発生しません。
:::

---

## OAuth 認証とは？

このログインでは **OAuth（オーオース）** という仕組みを使います。

OAuth とは、「Google や Anthropic のアカウントを使って、別のアプリにログインする仕組み」です。  
Gmail や Google カレンダーを使うとき「Google アカウントでログイン」するのと同じ仕組みです。  
パスワードを直接入力せず、安全にログインできます。

## ログイン手順

### ① ターミナルを開いてログインコマンドを実行する

ターミナル（macOS）または PowerShell（Windows）を開いて、以下を入力し `Enter` を押してください:

```bash
claude login
```

**このコマンドの意味:**  
`claude` = Claude Code に対して、`login` = 「ログインして」という命令です。  
このコマンドを実行すると、ブラウザが自動で開いてログイン画面が表示されます。

### ② ブラウザでログインする

自動的にブラウザが開き、Anthropic のログイン画面が表示されます。

**ブラウザが自動で開かない場合:**  
ターミナルに表示された URL（`https://claude.ai/...` で始まる文字列）をコピーして、ブラウザのアドレスバーに貼り付けてください。

### ③ ログイン方法を選択する

ブラウザのログイン画面で以下のいずれかを選択してください:

**Google アカウントでログインする場合:**
1. **「Continue with Google」** ボタンをクリック
2. Google アカウントの一覧が表示されたら、Claude Pro に登録したアカウントを選択
3. 「Claude にアクセスを許可しますか？」と表示されたら **「許可」** をクリック

**メールアドレスでログインする場合:**
1. メールアドレスを入力して **「Continue」** をクリック
2. 登録したメールアドレスに確認メールが届く
3. メール内の **「Confirm your email」** または **「こちらをクリック」** リンクをクリック

### ④ ターミナルに戻る

ブラウザでの認証が完了すると、ターミナルに以下のような表示が出ます:

```
✓ Logged in as your@email.com

 Claude Code  v1.x.x
 ...
>
```

**`>` または `?` のような記号**が表示されたら、命令の入力待ち状態です。ログイン完了です！

`Ctrl + C` を押すと終了できます。

## ログインの確認

次回以降は `claude` と入力するだけで自動的にログイン状態で起動します。  
認証情報はパソコンに安全に保存されるため、毎回ログインする必要はありません。
