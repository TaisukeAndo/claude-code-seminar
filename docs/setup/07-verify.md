# 7. 動作確認

すべてのセットアップが完了したら、Claude Code が正しく動作するか確認します。

## バージョン確認

```bash
claude --version
```

バージョン番号が表示されれば Claude Code CLI は正しくインストールされています。

## 簡単な動作テスト

任意のディレクトリでターミナルを開き、以下を実行してください:

```bash
claude
```

Claude Code が起動し、プロンプトが表示されれば成功です。

試しに以下を入力してみてください:

```
Hello! 自己紹介してください。
```

Claude からの返答が表示されれば、セットアップは**完了**です！
