# Session 1: 概念と仕組みを理解する

AIとうまく付き合うための「頭の中のモデル」を作るセッションです。  
**所要時間: 約 60 分**

## このセッションで学ぶこと

::: info セッション1のゴール
Claude Code をただの「ツール」として使うのではなく、**どんな原理で動いているかを理解した上で使う**ことが目的です。  
仕組みを知ることで、「なぜこういう指示が効くのか」「なぜ失敗したのか」がわかるようになります。
:::

## このセッションが重要な理由

Claude Code は非常に強力なツールですが、**仕組みを知らずに使うと「なんとなく動く・なんとなく失敗する」**という状態になりがちです。

- AIがどう「考えて」いるかを知ると、**より良いプロンプト（指示文）**が書けるようになる
- 失敗したときに**なぜ失敗したか**が推測できるようになる
- 自分でスキルを作るとき（Session 5）の**設計センス**が身につく
