## 7. コンテキストエンジニアリングとは ― リスクへの対策と準備の基盤

### このセクションで学ぶこと
- なぜ「設計」が必要か（リスク × コンテキストの制約）
- コンテキストエンジニアリングの定義と2つの役割
- CLAUDE.md（設計の入口）
- コンテキストを管理するスラッシュコマンド（/context・/clear・/compact・/remote）

### 2つの問題が重なっている

前のセクションで「リスクが増えた」とわかりました。実はもう一つ、別の問題もあります。

**問題① Claude Code のリスク**
自律的に動く = 意図しない操作・外部からの攻撃が起きうる。「何でもやらせる」ではまずい。

**問題② コンテキストウィンドウの制約**

> **【用語】コンテキストウィンドウ（Context Window）**
> 生成AIが「一度に覚えておける情報量」の上限。**トークン**（日本語で1〜2文字程度）という単位で測られる。会話履歴・ファイルの内容・コマンド結果・指示書などが全部この中に入る。
> **上限を超えると：** 古い会話から順に消えていく。Claudeは最大約20万トークン。
> （ソースあり：秋霜堂株式会社／Claude Code 公式ドキュメント）

イメージとしては**机の広さ**です。机が広くても無限ではないので、不要な書類を広げっぱなしにすると、本当に必要な資料を置くスペースがなくなります。

**2つの問題が重なる**：Claude Code は「自律的に大量の情報を読み込む」ため、コンテキストがどんどん消費されます。かつ「その情報に悪意ある指示が混じっているかもしれない」。

### 解決策：コンテキストエンジニアリング

> **【定義】コンテキストエンジニアリング（講師による定義）**
> 「**情報の整理であって、エージェントを育てる上で限りあるリソース（コンテキストウィンドウ）をどう使うか**というエンジニアリング」

つまり「**限られた机の上に、何を・いつ・どれだけ置くかを設計する技術**」です。

**コンテキストエンジニアリングの2つの役割：**

| 役割 | 何をするか |
|------|-----------|
|  **リスク対策の基盤** | 「何を許可するか」「何を遮断するか」を設計することで、意図しない操作や攻撃から守る |
| 🛠 **実践の準備** | 「どの情報をいつ読み込むか」を設計することで、次のハンズオンをスムーズに進める土台を作る |

### CLAUDE.md ― 設計の入口

コンテキストエンジニアリングの**入口**にあるのが CLAUDE.md です。

**CLAUDE.md とは：** Claude Code が起動するたびに**自動で読み込まれる**、プロジェクトの「永続的な指示書」。

| | プロンプト | CLAUDE.md |
|---|---|---|
| 効力の範囲 | その1回だけ | すべてのセッションで自動的に有効 |
| たとえると | その場の口頭指示 | 壁に貼ってある「職場のルール」 |

セッションをまたいで記憶してくれない Claude Code に、**「常に守ってほしいこと」を事前に設定しておく仕組み**です。プロンプトエンジニアリングで毎回書いていた指示を「一度書いて終わり」にできます。

**（補足・ソースあり）** CLAUDE.md が肥大化すると遵守率が下がるため、**200行以下が推奨**されています。
（ソースあり：Claude Code 公式ドキュメント／StartLink）

### コンテキストを管理するスラッシュコマンド

> **【用語】スラッシュコマンド**
> Claude Code の操作中に入力する「`/` から始まる特殊コマンド」。コンテキスト（机）を管理するための内部コマンド。

| コマンド | 何をする | 使いどき |
|----------|----------|----------|
| `/context` | コンテキストウィンドウの使用状況を**可視化**する | 「なんか重い」「どこを削れば軽くなる？」と思ったとき |
| `/clear` | 会話履歴をすべて消去し、コンテキストを**完全リセット** | 別のタスクに切り替えるとき |
| `/compact` | 会話履歴を**要約して圧縮**する（重要な情報は残す） | 同じ仕事を続けながら軽くしたいとき |
| `/remote-control` | Claude Code を**リモート（ブラウザ等）から操作**できる状態にする | 移動中や別端末から操作したいとき |

**`/clear` と `/compact` の違い：**

| | `/clear` | `/compact` |
|---|---|---|
| 会話の文脈 | **消える**（まっさら） | **残る**（要約して維持） |
| 向いている場面 | 完全に別の仕事を始めるとき | 同じ仕事を続けつつ軽くしたいとき |
