# Session 5: オリジナルスキル作成

自分だけのスキルを設計・実装するセッションです。スキルクリエイターを使って、自分の業務を自動化します。  
**所要時間: 約 90 分**

## このセッションで学ぶこと

::: info セッション5のゴール
Session 1〜4 で学んだことを活かして、**自分の業務に特化したオリジナルスキルを作る**体験をします。  
スキルクリエイターが設計から実装まで補助してくれます。
:::

## 学習内容の全体像

```
業務フローを分析  →  スキルを設計  →  スキルクリエイターで実装  →  テストと改善
       1.               2.                      3.                       4.
```

## チェックリスト

- [ ] **1.** 業務フローを分析する — 自分が毎日・毎週繰り返している作業を言語化する
- [ ] **2.** スキルを設計する — 入力・処理・出力を定義してスキルの仕様を決める
- [ ] **3.** スキルクリエイターで実装 — `/skill-creator` コマンドを使ってスキルを自動生成する
- [ ] **4.** テストと改善 — 実際に動かして問題点を見つけ、繰り返し改善する

## どんなスキルが作れる？

セミナー参加者が実際に作ったスキルの例:

| 業務 | 作ったスキル |
|---|---|
| 毎週の進捗報告 | Notion のタスクを読んで週次報告メールの下書きを作成 |
| 採用面接 | 候補者情報からヒアリングシートと評価フォームを自動生成 |
| 経費精算 | レシート写真から経費申請書 Excel を自動作成 |
| SNS 運用 | 週間投稿スケジュールから各プラットフォーム向けの原稿を一括生成 |
| 顧客対応 | お問い合わせメールから回答下書きと FAQ 候補を同時に生成 |

::: tip どんな業務でも自動化の候補になる
「毎回同じような作業をしている」「コピーして編集することが多い」「チェックリストが決まっている」  
こういった業務はほぼすべてスキル化できます。まずは思いつくままに書き出してみましょう。
:::
