# Session 5: セキュリティに気をつけながら自分でスキルを作る

Claude Code の基本操作（チャットやファイル操作）に慣れてきた方を対象に、**セキュリティを意識しながら自分自身でスキルを作れるようになること**を目指すセッションです。  
**所要時間: 約 90 分**

## このセッションで学ぶこと

::: info セッション5のゴール
Hooks・permission・.env ファイルの 3 つで **セキュリティ基盤を固め**、その上で **skill-creator を使って自分専用のスキルを安全に作る** 体験をします。
:::

## 学習内容の全体像

```
Hooks  →  permission  →  .envファイル  →  skill-creator  →  まとめ
  1.          2.              3.               4.              5.
```

## チェックリスト

- [ ] **1. Hooks** — 操作の直前・直後に自動で動く命令を理解する
- [ ] **2. permission** — できること・できないことをシステムレベルで決めるルールを学ぶ
- [ ] **3. .envファイル** — 秘密情報をコードから分離して安全に管理する
- [ ] **4. skill-creator** — 自分専用のスキルをゼロから作成する
- [ ] **5. まとめ** — 4 つの要素のつながりを整理する

## セキュリティ基盤の全体像

| 要素 | 一言でいうと | 主な役割 |
|---|---|---|
| Hooks | 操作の直前・直後に自動で動く命令 | 危険な操作の自動ブロック・監査ログ |
| permission | できること・できないことのルール | システムレベルでの許可・禁止 |
| .envファイル | 秘密情報の分離保管 | APIキーの漏洩リスク低減 |
| skill-creator | スキルを作るためのスキル | 安全な基盤の上でスキルを自動生成 |

::: tip セキュリティ基盤が先、スキル作成が後
Hooks・permission・.env ファイルの 3 つを理解してからはじめて、skill-creator を安全に使えます。  
1〜3 章が「守りの設定」、4 章が「攻めのスキル作成」です。
:::
