# よくある質問

## ターミナルについて

### ターミナルって何ですか？

**ターミナル**（またはコマンドプロンプト・PowerShell）は、テキストで命令を入力してコンピュータを操作するアプリです。

開き方は [1. 動作環境の確認](/setup/01-requirements#ターミナル-コマンド入力画面-とは) に詳しく記載しています。

### コマンドを入力したら文字が流れて何が起きているかわかりません

インストールや処理の進捗が表示されているため、**待ちの状態**です。止まるまで待ってください。  
新しい「`$`」や「`%`」や「`>`」のプロンプトが表示されたら処理完了のサインです。

### コマンドに大文字・小文字は関係ありますか？

はい、**大文字と小文字は区別されます**。必ずガイドに記載された通りに入力してください。  
コードブロック右上のコピーアイコンを使えば入力ミスを防げます。

## Node.js のインストール

### `npm: command not found` または `npm` が見つかりませんと表示される

Node.js がインストールされていないか、PATH が通っていません。

1. [2. Node.js インストール](/setup/02-nodejs-install) の手順を再確認
2. ターミナル（PowerShell）を一度**閉じて開き直す**
3. 再度 `node --version` を実行

### インストール中に進まなくなった

ネットワークが遅い場合、数分かかることがあります。  
5 分以上変化がない場合は `Ctrl + C` で中断し、再度実行してください。

## Claude Code CLI のインストール

### `claude: command not found` と表示される

Claude Code CLI が正しくインストールされていません。

```bash
npm install -g @anthropic-ai/claude-code
```

を再実行してください。それでも解決しない場合は PowerShell（ターミナル）を再起動してから試してください。

### Windows で「スクリプトの実行が無効」とエラーが出る

PowerShell を**管理者として実行**（スタートメニューで右クリック → 管理者として実行）して、以下を入力してください:

```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

「変更しますか？」と聞かれたら **`Y`** を入力して `Enter` を押してください。

## ログイン・認証

### ブラウザが自動で開かない

ターミナルに表示された URL（`https://claude.ai/...` で始まる文字列）をコピーして、ブラウザのアドレスバーに貼り付けてアクセスしてください。

### 「Pro プランに加入してください」と表示される

Claude Pro プランへの加入が必要です。[https://claude.ai/](https://claude.ai/) でプランを確認してください。

### Google アカウントでログインできない

1. まずブラウザで [https://claude.ai/](https://claude.ai/) に直接アクセスしてログインできるか確認
2. 別のブラウザ（Chrome / Edge / Safari）で試す
3. ブラウザのシークレットモード（プライベートモード）で試す

### 一度ログインしたのにまた認証を求められる

以下を実行してログアウト→再ログインしてください:

```bash
claude logout
claude login
```

## 接続・ネットワーク

### タイムアウトやネットワークエラーが出る

- インターネット接続を確認してください
- VPN を使用している場合は一時的に無効にしてみてください
- 職場や学校のネットワークで Anthropic のサーバーがブロックされている場合があります。その場合はスマートフォンのテザリングで試してください

## セミナー当日

### 当日、また確認することはありますか？

セミナー開始 10 分前に以下を確認してください:

```bash
claude --version   # バージョンが表示されるか確認
claude             # 起動するか確認（Ctrl+C で終了）
```

それでも解決しない問題は当日会場で講師にお声がけください。

### 当日の操作に不安があります

セミナー当日は講師が操作を一つひとつ説明しながら進めます。  
事前セットアップさえ完了していれば、当日は画面を見ながら一緒に進められます。安心してご参加ください。
