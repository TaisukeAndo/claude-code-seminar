# ステップ① Claude Pro プランへの加入

Claude Code を使うには、Anthropic が提供する **Claude Pro プラン**への加入が必要です。  
このページでは、アカウントの作成から Pro プランへの申し込みまでを説明します。

---

## Claude Pro とは？

Claude Pro は、Anthropic が提供する月額サブスクリプションのプランです。  
無料プランと比べて利用回数の制限が大幅に緩和されており、Claude Code もこのプランで使用します。

| | 無料プラン | Pro プラン |
|---|---|---|
| 月額料金 | 無料 | 約 $20（USD） |
| Claude との会話 | 回数制限あり | ほぼ制限なし |
| Claude Code の利用 | 使用不可 | 利用可能 |

---

## アカウントをまだ作っていない場合

すでに Claude のアカウントをお持ちの方は、次の「Pro プランへの申し込み」に進んでください。

### ① Claude のサイトにアクセスする

ブラウザで **[https://claude.ai/](https://claude.ai/)** を開いてください。

### ② アカウントを作成する

1. **「Sign up」** または **「アカウントを作成」** をクリック
2. 以下のいずれかを選択してください:
   - **「Continue with Google」** — Google アカウントでそのまま登録
   - **「Continue with email」** — メールアドレスで登録
3. 画面の案内に従ってアカウントを作成してください

---

## Pro プランへの申し込み

### ① Claude にログインする

**[https://claude.ai/](https://claude.ai/)** にアクセスし、作成したアカウントでログインしてください。

### ② プランのアップグレード画面を開く

ログイン後の画面で、以下のいずれかをクリックしてください:

- 画面左下または右上に表示される **「Upgrade to Pro」**
- メニュー内の **「プランの変更」** や **「Plan」**

### ③ Pro プランを選択する

プラン選択画面が表示されたら:

1. **「Pro」** プランの **「Subscribe」** または **「申し込む」** をクリック

### ④ 支払い情報を入力する

支払いフォームが表示されます:

1. **クレジットカード番号** を入力
2. **有効期限**（月 / 年）を入力
3. **セキュリティコード**（カード裏面の3桁または表面の4桁の数字）を入力
4. 請求先の **国・地域** を選択
5. **「Subscribe」** または **「申し込む」** をクリック

::: info 支払いについて
- 料金は月額約 $20 USD です。日本円での実際の請求額はご利用のクレジットカードの換算レートにより変わります。
- 毎月同じ日に自動更新されます。
:::

### ⑤ 申し込みを確認する

申し込みが完了すると、登録したメールアドレスに確認メールが届きます。  
Claude のサイトに戻り、アカウントメニューに **「Pro」** と表示されていれば申し込み完了です。
