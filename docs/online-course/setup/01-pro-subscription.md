# ステップ① Claude Pro プランへの加入

Claude Code を使うには、Anthropic が提供する **Claude Pro プラン**への加入が必要です。  
このページでは、アカウントの作成から Pro プランへの申し込みまでを説明します。

## Claude Pro とは？

Claude Pro は、Anthropic が提供する月額サブスクリプションのプランです。  
無料プランと比べて利用回数の制限が大幅に緩和されており、Claude Code もこのプランで使用します。

| | 無料プラン | Pro プラン |
|---|---|---|
| 月額料金 | 無料 | 約 $20（USD） |
| Claude との会話 | 回数制限あり | ほぼ制限なし |
| Claude Code の利用 | 使用不可 | 利用可能 |

## アカウントをまだ作っていない場合

すでに Claude のアカウントをお持ちの方は、次の「Pro プランへの申し込み」に進んでください。

### ① Claude のサイトにアクセスする

ブラウザで **[https://claude.ai/](https://claude.ai/)** を開いてください。

### ② 「Sign up」からアカウントを作成する

画面中央または右上にある **「Sign up」** ボタンをクリックしてください。

登録方法を選択する画面が表示されます:

- **「Continue with Google」** をクリック — お持ちの Google アカウントでそのまま登録されます
- **「Continue with Apple」** をクリック — Apple ID で登録されます
- **「Continue with email」** をクリック — メールアドレスと任意のパスワードを入力して登録します

### ③ 名前と利用規約の確認

名前の入力と利用規約への同意画面が表示されます。  
内容を確認し、**「Continue」** をクリックしてください。

## Pro プランへの申し込み

### ① プランページを開く

ブラウザで **[https://claude.com/pricing](https://claude.com/pricing)** を開いてください。

Pro プランを含む各プランの比較表が表示されます。

### ② Pro プランの「Try Claude」をクリックする

**「Pro」** プランの欄にある **「Try Claude」** ボタンをクリックしてください。

ログインしていない場合はログイン画面が表示されます。作成したアカウントでログインしてから操作を続けてください。

### ③ 支払い情報を入力する

支払いフォームが表示されます:

1. **メールアドレス** を確認（自動入力されている場合はそのまま）
2. **カード番号** を入力（16桁）
3. **有効期限**（MM / YY の形式）を入力
4. **セキュリティコード（CVC）** を入力 — カード裏面に記載の 3 桁の数字
5. **カード名義**（ローマ字）を入力
6. **国または地域** で **「Japan」** を選択
7. **「Subscribe」** ボタンをクリック

::: info 支払いについて
- 料金は月額約 $20 USD です。日本円での実際の請求額はご利用のクレジットカードの換算レートにより変わります。
- 毎月同じ日に自動更新されます。解約はいつでも設定画面から行えます。
:::

### ④ 申し込みの確認

支払いが完了すると、登録したメールアドレスに領収書メールが届きます。  
[https://claude.ai/](https://claude.ai/) に戻りログインすると、画面左下のアカウントエリアに **「Pro」** と表示されていれば申し込み完了です。
