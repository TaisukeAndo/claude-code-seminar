# ステップ③ Git のインストール

Claude Code を使うにあたって、**Git（ギット）** というソフトが必要です。  
このページでは Git のインストールと初期設定を行います。

## Git とは？

Git は、ファイルの**変更履歴を記録・管理するソフト**です。

たとえば、文書を編集するたびに「いつ・何を・なぜ変更したか」を自動で記録できます。  
間違えた場合に以前の状態に戻したり、複数人で同じファイルを編集するときに使います。

Claude Code はプロジェクトのファイルを管理する際に Git を内部で使用するため、  
事前にインストールしておく必要があります。

## インストール手順 — macOS

### 方法 A: ターミナルから自動インストール（推奨・追加ソフト不要）

1. **ターミナル**を開く
   - キーボードの **`⌘（Command）+ スペース`** を押して Spotlight 検索を開く
   - 「ターミナル」と入力し、候補に表示された **「ターミナル」** をクリック

2. 黒いウィンドウ（ターミナル）が開いたら、以下をそのまま入力して **`Return（Enter）`** を押す:

   ```bash
   git --version
   ```

3. 「開発者ツールをインストールする必要があります」というダイアログが表示されたら **「インストール」** をクリック
4. インストールが完了するまで待つ（5〜10 分程度）
5. 完了後、再度 `git --version` を入力して `git version 2.x.x` のように表示されれば成功

### 方法 B: Homebrew を使う（すでに Homebrew が入っている場合）

```bash
brew install git
```

## インストール手順 — Windows

### ① Git for Windows をダウンロードする

ブラウザで **[https://git-scm.com/download/win](https://git-scm.com/download/win)** を開いてください。  
ページが開くと自動でダウンロードが始まります。始まらない場合は **「Click here to download」** リンクをクリックしてください。

### ② インストールする

1. ダウンロードフォルダにある **`Git-x.x.x-64-bit.exe`** をダブルクリック
2. 「このアプリがデバイスに変更を加えることを許可しますか？」→ **「はい」**
3. インストール画面が開く — **設定はすべてデフォルト（変更なし）** のまま **「Next」** をクリックし続ける
4. 最後の画面で **「Install」** をクリックし、完了したら **「Finish」** をクリック

::: info インストール中の選択肢について
インストール画面にはさまざまな設定項目が表示されますが、  
すべてデフォルト（変更なし）のまま進めて問題ありません。
:::

## インストールの確認

Git が正しくインストールされたか確認します。

**macOS の場合:** ターミナルを開いて以下を入力

**Windows の場合:** スタートメニューを開き「Git Bash」と検索して起動し、以下を入力

```bash
git --version
```

以下のようにバージョン番号が表示されれば成功です:

```
git version 2.x.x
```

## 初期設定（名前とメールアドレスの登録）

Git を使う前に、「誰が変更したか」を記録するための名前とメールアドレスを登録します。  
この情報は変更履歴に記録されますが、外部に公開されるものではありません。

ターミナル（または Git Bash）に以下を **1 行ずつ** 入力して `Enter` を押してください。  
`"山田 太郎"` と `"taro@example.com"` の部分はご自身の名前とメールアドレスに変更してください:

```bash
git config --global user.name "山田 太郎"
```

```bash
git config --global user.email "taro@example.com"
```

### 設定の確認

以下のコマンドで、設定が正しく保存されたか確認できます:

```bash
git config --global user.name
git config --global user.email
```

入力した名前とメールアドレスがそれぞれ1行ずつ表示されれば設定完了です。
