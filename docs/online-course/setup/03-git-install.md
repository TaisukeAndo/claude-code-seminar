# ステップ③ Git のインストール

Claude Code を使うにあたって、**Git（ギット）** というソフトが必要です。  
このページでは Git のインストールと初期設定を行います。

## Git とは？

Git は、ファイルの**変更履歴を記録・管理するソフト**です。

たとえば、文書を編集するたびに「いつ・何を・なぜ変更したか」を自動で記録できます。  
間違えた場合に以前の状態に戻したり、複数人で同じファイルを編集するときに使います。

Claude Code はプロジェクトのファイルを管理する際に Git を内部で使用するため、  
事前にインストールしておく必要があります。

## インストール手順 — macOS

### 方法 A: Xcode Command Line Tools を使う（推奨・追加ソフト不要）

1. **ターミナル**を開く  
   Spotlight 検索（`⌘ + スペース`）で「ターミナル」と入力して起動

2. 以下のコマンドを入力して `Enter` を押す:

   ```bash
   git --version
   ```

3. Git がインストールされていない場合、「開発者ツールが必要です」というダイアログが表示される
4. **「インストール」** をクリックして待つ（5〜10 分程度）
5. 完了後、再度 `git --version` を実行してバージョンが表示されれば成功

### 方法 B: Homebrew を使う（すでに Homebrew が入っている場合）

```bash
brew install git
```

## インストール手順 — Windows

### ① Git for Windows をダウンロードする

1. ブラウザで **[https://git-scm.com/download/win](https://git-scm.com/download/win)** を開く
2. **「64-bit Git for Windows Setup」** をクリックしてダウンロード

### ② インストールする

1. ダウンロードした **`.exe`** ファイルをダブルクリック
2. 「このアプリがデバイスに変更を加えることを許可しますか？」→ **「はい」**
3. インストール画面が開くので、**設定はすべてデフォルト（そのまま）** で **「Next」** をクリックし続ける
4. 最後に **「Install」** → **「Finish」** をクリック

::: info インストール中の選択肢について
インストール画面にはさまざまな設定項目が表示されますが、  
すべてデフォルト（変更なし）のまま進めて問題ありません。
:::

## インストールの確認

Git がインストールできたか確認します。

**macOS** はターミナル、**Windows** は「Git Bash」または「コマンドプロンプト」を開いて以下を入力:

```bash
git --version
```

以下のようにバージョン番号が表示されれば成功です:

```
git version 2.x.x
```

## 初期設定（名前とメールアドレスの登録）

Git を使う前に、「誰が変更したか」を記録するための名前とメールアドレスを登録します。  
この情報は変更履歴に記録されますが、外部に公開されるものではありません。

ターミナル（または Git Bash）で以下を 1 行ずつ入力してください。  
`"山田 太郎"` と `"taro@example.com"` の部分はご自身の名前とメールアドレスに変更してください:

```bash
git config --global user.name "山田 太郎"
```

```bash
git config --global user.email "taro@example.com"
```

### 設定の確認

以下のコマンドで設定が正しく保存されたか確認できます:

```bash
git config --global user.name
git config --global user.email
```

入力した名前とメールアドレスが表示されれば設定完了です。
