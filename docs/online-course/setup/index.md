# セットアップの全体像

Claude Code Desktop 版を使い始めるまでの 4 ステップを説明します。  
**所要時間の目安: 約 30〜40 分**

::: info このガイドについて
プログラミングやコマンド操作の経験がない方を対象に、画面の操作手順をできるだけ丁寧に説明しています。  
わからない言葉が出てきた場合は、その都度解説を記載していますので、順番に読み進めてください。
:::

## チェックリスト

- [ ] **ステップ①** [Claude Pro プランへの加入](/online-course/setup/01-pro-subscription) — 月額プランへの申し込みと支払い
- [ ] **ステップ②** [Claude Desktop のインストール](/online-course/setup/02-desktop-install) — アプリのインストールと Claude Code の有効化
- [ ] **ステップ③** [Git のインストール](/online-course/setup/03-git-install) — 変更履歴管理ソフトのインストール
- [ ] **ステップ④** [MCP サーバーの接続設定](/online-course/setup/04-mcp-setup) — 外部サービスとの連携設定

## 事前に必要なもの

- インターネット接続
- クレジットカード（Claude Pro への加入時に使用）
- Google アカウント（MCP 接続時に使用）
