## 3.17. MCP と API — 2 つの連携方式

会計ソフトとの連携の話に入る前に、セッション 1 でも触れた **MCP** と **API** について改めて整理します。  
どちらも「外部のサービスと情報をやりとりする仕組み」ですが、使い方と得意・不得意が異なります。

### MCP（Model Context Protocol）とは

MCP は、AI（LLM）がテキストで指示を受けて外部サービスを操作するための仕組みです。

```
あなた → 「カレンダーの今日の予定を教えて」
              ↓（MCP 経由）
         Google カレンダーを参照して予定を取得
              ↓
         「今日は 14:00〜 打ち合わせがあります」
```

**MCP の特徴**

| 項目 | 内容 |
|---|---|
| 指示の形式 | 自然な日本語で指示できる |
| 対応操作 | 1 回の指示で複数の操作をまとめて実行できる |
| サービス側の提供 | サービス事業者が MCP サーバーを用意する |
| 主な用途 | 情報の読み取り（参照系）が中心 |

### API（Application Programming Interface）とは

API は、プログラムがサービスに対して「この操作をしてください」と細かく指定する仕組みです。

```
プログラム → 「この URL に、この形式でデータを送ってください」
                       ↓（API 経由）
              サービスがデータを処理して結果を返す
```

**API の特徴**

| 項目 | 内容 |
|---|---|
| 指示の形式 | URL と決められたデータ形式（JSON など）で指定する |
| 対応操作 | 1 つの操作（読む・書く・更新する・削除する）に 1 つの URL が対応する |
| サービス側の提供 | サービス事業者が API を公開している |
| 主な用途 | 読み取りも書き込みも可能 |

## 3.18. なぜ会計ソフトの連携には API を使うのか

マネーフォワード・freee・弥生会計はいずれも MCP を提供しています。  
しかし、**会計データへの書き込みは API を使います**。理由は 2 つです。

### 理由 1：お金が絡む処理には精密さが必要

MCP はテキストで指示を出すため、自然言語のあいまいさが残ります。  
「見積書を作って」という指示で金額に誤りが生じても、AI は気づきにくいことがあります。

API を使うと、「品目名」「数量」「単価」「税率」を個別のフィールドとして指定できるため、  
**誤りが起きにくく、確認もしやすい**設計になります。

### 理由 2：会計ソフトの MCP は書き込みを制限している

各社の MCP サーバーは、現時点では**参照（読み取り）が中心**で、  
データの作成・更新・削除（書き込み）については制限されていることが多いです。

```
MCP でできること（現時点）:
  ✅ 売上一覧・請求書一覧を読み取る
  ✅ 取引先情報を確認する
  ❌ 見積書・請求書を新規作成する（制限あり）
  ❌ 仕訳データを書き込む（制限あり）

API でできること:
  ✅ 見積書・請求書を新規作成する
  ✅ 仕訳データを送信する
  ✅ 取引先を登録する
```

### invoice-creator スキルの設計

invoice-creator スキルは、この事情をふまえて次のように設計されています。

```
STEP 1: Claude Code が内容をヒアリング
            品目・数量・単価・税率・取引先を確認する
            ※ 住所・口座番号などの個人情報はローカルファイルで管理（LLM には渡さない）
         ↓
STEP 2: document.json を生成
            品目・金額・日付など業務内容のみを含むファイルを作る
         ↓
STEP 3: Python スクリプトが出力形式に変換
            Excel → .xlsx ファイルを生成
            マネーフォワード → API で直接送信 または 取り込み用 CSV を生成
            freee → 取り込み用 CSV を生成
            弥生会計 → 取り込み用 CSV を生成
```

### Excel で会計処理をしている場合

xlsx-creator または invoice-creator スキルの Excel 出力をそのまま使えます。  
追加の API 設定は不要です。ハンズオン（3.19.〜3.23.）は **3.19. と 3.20.** だけ実施して完了です。

### マネーフォワード・freee・弥生会計を使っている場合

API キーの取得と設定が必要です。ハンズオンでは **3.21. 以降**の手順も実施してください。  
このドキュメント内に各サービスの API キー発行手順を記載しています。
