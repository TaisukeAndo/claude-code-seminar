## 3.1. このセッションで目指す完成形

このセッションの終わりに、参加者それぞれが以下の状態に到達していることを目標とします。

### 完成物のイメージ

**xlsx-creator スキル（3.9.〜3.13.）**

Claude Code に「KPI管理表を作って」と指示するだけで、以下のような Excel ファイルが自動生成されます。

```
出力例:
────────────────────────────────────────────
  月次KPI管理表（小売業向け）

  シート 1: KPI ダッシュボード
    月次売上目標: 500万円（業界平均: 480万円）
    新規顧客数目標: 120名
    CVR 目標: 3.2%（業界平均: 2.8%）

  シート 2: タスク一覧
    No. / タスク名 / 担当者 / 開始日 / 期限 / ステータス / 進捗
    ▶ ステータスを「完了」に変えると行が緑色になる
────────────────────────────────────────────
ファイル形式: .xlsx（Excel で開ける）
```

**invoice-creator スキル（3.19.〜3.23.）**

「見積書を作って」の一言で、会計ソフトに取り込めるファイルが出力されます。

```
出力例:
────────────────────────────────────────────
  見積書 EST-2026-001

  件名: Webサイト制作費用
  品目 1: システム設計・開発   1式  500,000円
  品目 2: デザイン制作         1式  150,000円
  ────────────────
  小計: 650,000円
  消費税（10%）: 65,000円
  合計: 715,000円

  出力形式: Excel / マネーフォワードCSV / freeeCSV / 弥生会計CSV
────────────────────────────────────────────
```

## 3.2. 普段の Excel 活用について話し合う

**時間: 5 分**

::: info グループワーク
近くの参加者と 3〜4 人のグループを作り、以下の 4 つのテーマで話し合ってください。  
全部話しきれなくても構いません。気になるテーマから話し始めてください。
:::

**テーマ 1：仕事でどんな種類の Excel ファイルを使っていますか？**

| 種類の例 | 主な用途 |
|---|---|
| 売上・KPI の管理表 | 月次・週次の数値を追う |
| プロジェクト・タスク管理表 | 誰が何をいつまでにやるか |
| 見積書・請求書・経費精算書 | お金の動きを記録する |
| 在庫・受注・顧客管理 | データを一覧で把握する |
| 勤怠・シフト管理 | 人員の調整を行う |

**テーマ 2：そのファイルはどうやって作っていますか？**

テンプレートを流用しているか、毎回一から作っているか、誰かに作ってもらっているか、  
普段の「作り方のルーティン」を共有してください。

**テーマ 3：数値・データはどこから持ってきていますか？**

| 情報の入手方法の例 |
|---|
| システムやツールから CSV でダウンロードする |
| 担当者が手で数値を入力・転記する |
| 過去のファイルを開いてコピーして書き換える |
| Web で調べた数値を手入力する |

**テーマ 4：Excel 作業の中でいちばん手間がかかるのはどこですか？**

「ここに毎回時間をとられる」「この作業が面倒だ」という工程を共有してください。

::: tip ファシリテーターへのメモ
5 分後に各グループから印象に残った内容を 1〜2 個ずつ発表してもらいます。
:::

## 3.3. 自分の Excel 活用フローを書き出す

**時間: 5 分**

グループでの話し合いを踏まえて、個人作業です。  
以下の 4 つの質問に答えながら、**自分が Excel ファイルを作るときの全体像**を書き出してください。

### 質問 1：よく使う Excel ファイルを 1〜3 種類書き出してください

ファイルの名前と、どのくらいの頻度で使うか（毎週・月1回など）も一緒に書いてください。

### 質問 2：そのファイルにどんなデータが入っていますか？

以下の観点で書き出してください。

- シートの数と名前
- 主な列（項目名）
- 手で入力しているデータと、どこかから持ってきているデータの区別
- ファイルを見る人（自分だけ・チーム・上司・クライアントなど）

### 質問 3：ファイルを作る・更新するまでの手順はどうなっていますか？

「何から始めるか」から「完成・提出するまで」の手順を順番に書いてください。

### 質問 4：Excel 作業にかかる時間の内訳は？

1 つのファイルを完成させるまでに、どの工程にどれくらい時間がかかるかを書いてください。

```
（記入例）
・ベースのテンプレートをコピーして日付を直す: 5分
・他ツールからデータをダウンロードして貼り付ける: 20分
・計算式がずれていないか確認する: 10分
・上司に提出して修正依頼が来る: 翌日〜数日後
・合計: 作業自体は35分、でも完成まで数日かかることも
```
