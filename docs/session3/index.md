# Session 3: Excelデータ分析と会計処理の自動化

このセッションが終わると、**「KPI管理表を作って」「タスクをExcelで整理して」という一言だけで**、  
業界ベンチマークを調べてデータが揃ったExcelファイルが自動で完成するようになります。  
さらに、見積書・請求書を会計ソフトに連携する流れも自動化できます。

---

## このセッションで実現すること

### KPI管理表・タスク管理表の自動生成（xlsx-creator スキル）

Claude Code に目的と業種を伝えるだけで、業界ベンチマーク入りのExcelファイルが数分で完成します。

```
出力例:
────────────────────────────────────────────
  月次KPI管理表（EC サイト運営）

  シート 1: KPI ダッシュボード
    月次売上 / 新規顧客数 / CVR / 平均単価
    ▶ 業界平均と自社目標を並べて比較できる

  シート 2: タスク管理
    タスク名 / 担当者 / 期限 / ステータス（ドロップダウン）
    ▶ 進捗をドロップダウンで選ぶだけで色が変わる

────────────────────────────────────────────
ファイル形式: .xlsx（Excel で開ける）
```

### 見積書・請求書の自動生成と会計連携（invoice-creator スキル）

「見積書を作って」の一言で、Excel 形式はもちろん、マネーフォワード・freee・弥生会計に取り込める形式でも出力できます。
