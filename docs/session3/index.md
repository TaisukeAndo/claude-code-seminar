# Session 3: 会計処理の自動化

Excel データ処理から MoneyForward・会計 freee との API 連携まで、会計・見積もり業務を自動化するセッションです。  
**所要時間: 約 75 分**

## このセッションで学ぶこと

::: info セッション3のゴール
毎月手作業で行っている**見積もり作成・請求書作成・データ集計**を Claude Code のスキルに任せられるようにします。  
API 連携の設定方法と、実際に動くスキルを体験します。
:::

## 学習内容の全体像

```
Excelデータ処理  →  MoneyForward API設定  →  見積もり作成スキル  →  請求書作成スキル
       1.                    2.                       3.                     4.
```

## チェックリスト

- [ ] **1.** [Excelデータ処理の自動化](/session3/01-excel-data) — CSV・Excel の読み込みと集計を Claude Code に任せる
- [ ] **2.** [MoneyForward API設定](/session3/02-moneyforward-setup) — API キーの取得とクレデンシャル設定
- [ ] **3.** [見積もり作成スキル](/session3/03-create-estimate) — 「見積もりを作って」の一言で MoneyForward に見積書を作成
- [ ] **4.** [請求書作成スキル](/session3/04-create-invoice) — 見積もりから請求書への変換を自動化

## 対応サービス

| サービス | 用途 | Session で扱う内容 |
|---|---|---|
| MoneyForward クラウド請求書 | 見積書・請求書作成 | API 連携・自動作成 |
| 会計 freee | 会計・確定申告 | API 連携・データ送信 |
| Microsoft Excel / Google Sheets | データ集計 | ファイル読み込み・加工 |

::: warning API 利用について
MoneyForward・freee の API を利用するには**有料プラン**が必要な場合があります。  
セミナー当日は講師のデモアカウントを使用して進めますが、自分のアカウントで設定する際は各サービスのプラン条件をご確認ください。
:::
