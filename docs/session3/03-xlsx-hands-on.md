# xlsx-creator ハンズオン

**所要時間: 約 20 分（手を動かす作業）**

このページはすべて実際に操作する作業です。  
1 ステップずつ確認しながら進めてください。

---

## 3.9. エージェントフォルダをダウンロードする

xlsx-creator スキルはサブエージェントを使います。Session 2 でまだダウンロードしていない場合は、ここで行ってください。

**① ターミナルを開いてプロジェクトフォルダに移動する**

```bash
cd ~/Desktop/claude-code-seminar
```

**② エージェントフォルダをダウンロードする**

Session 2 で既にダウンロード済みの場合はこの手順をスキップしてください。

```bash
npx degit TaisukeAndo/claude-code-seminar/.claude/agents .claude/agents
```

完了すると以下のように表示されます。

```
> cloned TaisukeAndo/claude-code-seminar#HEAD
```

**③ ダウンロードされたファイルを確認する**

```bash
ls .claude/agents/
```

以下のファイルが表示されれば成功です。

```
excel-structure-researcher.md    web-researcher.md
```

## 3.10. xlsx-creator スキルをダウンロードする

**① スキルフォルダに移動する**

```bash
cd .claude/skills
```

**② xlsx-creator スキルをダウンロードする**

```bash
npx degit TaisukeAndo/claude-code-seminar/.claude/skills/xlsx-creator xlsx-creator
```

**③ ダウンロードされたファイルを確認する**

```bash
ls xlsx-creator/
```

以下のファイルとフォルダが表示されれば成功です。

```
SKILL.md    references/    scripts/
```

| ファイル・フォルダ | 役割 |
|---|---|
| `SKILL.md` | スキルの設定ファイル。トリガー文言・処理手順が書かれている |
| `references/` | task・kpi・forms 各タイプの詳細設計ガイドが入っているフォルダ |
| `scripts/` | Excel ファイルを生成する Python スクリプト（`create_xlsx.py`） |

**④ 依存ライブラリをインストールする**

xlsx-creator は `openpyxl` というライブラリを使って Excel ファイルを生成します。

```bash
pip3 install openpyxl
```

インストールが完了すると以下のように表示されます。

```
Successfully installed openpyxl-X.X.X
```

## 3.11. Excel ファイルを生成する

**① プロジェクトのルートフォルダに戻る**

```bash
cd ~/Desktop/claude-code-seminar
```

**② Claude Code を起動する**

```bash
claude
```

以下の画面が表示されれば起動成功です。

```
╭───────────────────────────────────────╮
│ ✻ Welcome to Claude Code!             │
╰───────────────────────────────────────╯

> 
```

**③ Excel ファイルの生成を指示する**

`>` プロンプトに以下を入力して `Enter` を押してください。

```
月次KPI管理表を作ってください。
業種: Webサービスを提供するIT企業
管理したいKPI: 月次売上、新規ユーザー登録数、解約率（チャーンレート）、顧客満足度スコア
計測期間: 月次
目標値: 設定できるようにしてほしい
```

::: tip 自分の業務内容で試してみる
自分が実際に必要としている Excel ファイルの内容で試すと、使いやすさの確認がしやすくなります。  
グループワークで書き出した「よく使う Excel」を題材にしてみましょう。
:::

生成には 2〜3 分程度かかります。ターミナルに文字が流れている間は待ってください。  
サブエージェントが起動して情報収集を行うため、Session 2 のスキルより少し時間がかかる場合があります。

**④ 生成されたファイルを確認する**

処理が完了すると、プロジェクトフォルダ内に `.xlsx` ファイルが生成されます。

macOS の場合:
1. Finder を開く
2. `~/Desktop/claude-code-seminar` フォルダを開く
3. 生成された `.xlsx` ファイルをダブルクリックして Excel または Numbers で開く

Windows の場合:
1. エクスプローラーを開く
2. デスクトップの `claude-code-seminar` フォルダを開く
3. 生成された `.xlsx` ファイルをダブルクリックして Excel で開く

## 3.12. 内容を確認して修正を指示する

生成された Excel ファイルを確認し、修正が必要な箇所があれば Claude Code に指示を出します。

### 確認チェックリスト

**シート構成の確認**
- [ ] 必要なシートがすべてあるか
- [ ] 列（項目）が自分の業務に合っているか
- [ ] ドロップダウンの選択肢が実情に合っているか

**数値・データの確認**
- [ ] 業界平均や参考数値が入っている場合、出典が示されているか
- [ ] 単位（円・件・%など）が正しく設定されているか

### 修正指示の例

**シートを追加したい場合:**
```
タスク管理のシートも追加してください。
担当者のドロップダウンには「田中・鈴木・佐藤」を入れてください。
```

**列を変更したい場合:**
```
「顧客満足度スコア」の列名を「NPS（ネットプロモータースコア）」に変更してください。
また、-100 から 100 の範囲で入力できるように設定してください。
```

**デザインを変えたい場合:**
```
ヘッダー行の色を会社のコーポレートカラー（#1E3A5F）に変更してください。
```

## 3.13. よくある失敗パターンと対処法

| 現象 | 考えられる原因 | 対処方法 |
|---|---|---|
| ファイルが生成されない | `openpyxl` がインストールされていない | 3.10. の④を再実行してください |
| Excel で開けない | Excel がインストールされていない | Numbers（macOS）または Google スプレッドシートで開く |
| 数値が空欄になっている | 業種・KPI の情報が少なかった | 「業種と管理したいKPI」を具体的に伝えて再実行する |
| エラーメッセージが出る | スキルのダウンロードが不完全 | 3.10. の手順を再度実行する |
| サブエージェントが起動しない | エージェントフォルダが存在しない | 3.9. の手順を再度実行する |
