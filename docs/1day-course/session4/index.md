# Session 4: 定常業務の自動化

毎日繰り返している業務（Slack・Gmail・ToDoリスト管理）を Claude Code に丸ごと任せるセッションです。  
**所要時間: 約 75 分**

## このセッションで学ぶこと

::: info セッション4のゴール
朝のルーティン「Slack を確認して、メールに返信して、今日のタスクをまとめる」を**1 つのコマンドで実行できる**ようにします。  
返信はあくまで「下書き」として作成され、送信前に確認できます。
:::

## 学習内容の全体像

```
Slackキャッチアップ  →  Gmail返信下書き  →  ToDoリスト管理  →  日次ルーティン統合
         1.                    2.                  3.                  4.
```

## チェックリスト

- [ ] **1.** Slackキャッチアップ — 複数ワークスペースのメンションと要返信メッセージを自動収集
- [ ] **2.** Gmail返信下書き — 未読メールを取得して AI が返信の下書きを自動作成
- [ ] **3.** ToDoリスト管理 — Google Tasks と連携してタスクの確認・追加を自動化
- [ ] **4.** 日次ルーティンの統合 — 上記を 1 コマンドで一括実行する朝のルーティンスキル

## 自動化できる業務の例

| 業務 | 手作業の場合 | 自動化後 |
|---|---|---|
| Slack チェック | 全チャンネルを手動で確認（10〜20分） | 要対応メッセージのみ抽出（1分） |
| メール返信 | 1通ずつ読んで返信文を考える（30〜60分） | 下書きが自動作成される（5分で確認・送信） |
| タスク整理 | 手書きやアプリに手動入力（10〜15分） | 会話から自動でToDoに追加 |

::: warning 返信は「下書き」として保存されます
このセッションで作るスキルは、**メールの送信・Slack への投稿は行いません**。  
下書きを作成するだけなので、送信前に内容を確認・編集できます。安心して使えます。
:::

## 事前準備の確認

- [ ] Gmail アカウントにアクセスできる状態になっている
- [ ] Slack にログインしている（ワークスペースが 1 つ以上ある）
- [ ] Google Tasks または他のToDoツールを使っている
