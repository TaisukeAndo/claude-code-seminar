## 3.5. Excel 作成フローの課題

Session 2 ではドキュメントとスライドの自動生成を学びました。  
Excel ファイルの自動生成でも、設計の考え方は同じです。

### なぜ Excel 作成に時間がかかるのか

グループワークで話し合った内容を振り返ると、多くの場合に次の 3 つの工程が手作業になっています。

```
課題 1: 数値・相場の収集
  → 業界平均や競合数値をウェブで調べて、手でコピーして貼り付けている

課題 2: 構成の設計
  → 「どんな列が必要か」を毎回ゼロから考えている
    または、古いファイルを流用して手直ししている

課題 3: フォーマットの整形
  → 色付け・ドロップダウン・条件付き書式の設定に時間がかかっている
```

xlsx-creator スキルは、この 3 つをすべてスキルが担います。

## 3.6. サブエージェントが担う「調べる」役割

Session 2 のドキュメント・スライドと同様に、xlsx-creator スキルも**サブエージェント**を活用しています。

xlsx-creator スキルでは、目的に応じて 2 種類のサブエージェントが起動します。

### サブエージェント 1：web-researcher（データ収集担当）

業界のベンチマークや相場情報をウェブで調べて、数値の根拠を集めます。

```
依頼例（KPI管理表を作るとき）:
→ 「小売業の月次CVRの業界平均」「EC サイトの新規顧客獲得コストの相場」
  などをウェブ検索して調べる

依頼例（タスク管理表を作るとき）:
→ 「展示会準備の一般的なタスク一覧」「新製品ローンチに必要な工程」
  などを調べてタスク構成の参考にする
```

::: info web-researcher について
web-researcher はインターネット検索を行うサブエージェントです。  
KPI の目標値を設定するとき、「自社だけの感覚」ではなく「業界の実態」を参考にできるため、  
より根拠のある数値をExcelに入れることができます。
:::

### サブエージェント 2：excel-structure-researcher（構成リサーチ担当）

「何の管理表を作るか」が決まったら、その種類のExcelに最適な列・シート構成をリサーチします。

```
依頼例:
→ 「営業パイプライン管理表（BtoB）の標準的な列構成は？」
→ 「飲食店の勤怠管理表に必要な項目は？」
→ 「製造業の在庫管理Excelの一般的なシート構成は？」
```

excel-structure-researcher は、Microsoft 公式テンプレートや業界団体の様式なども参照して、  
業種・用途に合った構成を返します。

## 3.7. Excel 作成フローが AI に変わるとどうなるか

グループワークで書き出した作業フローと比較してみましょう。

```
【従来のフロー】
STEP 1: 何が必要か考えてベースになるファイルを探す
            （以前作ったファイル・ネット上のテンプレートを探す）
         ↓
STEP 2: 必要な数値・相場を調べる
            （Web 検索→コピー→Excelに貼り付け）
         ↓
STEP 3: 列を整理してレイアウトを作る
            （ヘッダーの並べ替え・セル幅の調整）
         ↓
STEP 4: 色付け・ドロップダウン・条件付き書式を設定する
            （設定画面を開いて一項目ずつ設定）
```

```
【xlsx-creator スキルを使ったフロー】
STEP 1: 目的・業種・管理したいKPIをスキルに伝える
            （Claude Code に一言で指示）
         ↓
STEP 2: excel-structure-researcher が構成をリサーチする（自動）
            ↕（並行して）
         web-researcher が業界データを収集する（自動）
         ↓
STEP 3: .xlsx ファイルが生成される（数分）
            色付け・ドロップダウン・条件付き書式は自動で設定済み
         ↓
STEP 4: 内容を確認して修正を指示する（あなたの作業）
```

## 3.8. xlsx-creator スキルの対応タイプ

このスキルが扱える Excel の種類は、大きく 4 つに分類されています。

| タイプ | 対象 | 主なシート構成の例 |
|---|---|---|
| **task**（タスク管理） | プロジェクト管理・工程表・進行管理 | タスク一覧・ガントチャート・担当者別ビュー |
| **kpi**（KPI管理） | マーケティング・目標管理・実績集計 | KPIダッシュボード・月次推移・目標vs実績 |
| **forms**（帳票） | 見積書・請求書・経費精算書 | 帳票シート・明細リスト |
| **free**（その他） | 上記以外すべて | excel-structure-researcher がリサーチして設計 |

「どのタイプか」を Claude Code が自動で判断するため、  
**あなたは何を作りたいかを自然な言葉で伝えるだけ**です。
