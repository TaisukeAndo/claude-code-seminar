## 3.14. 普段の会計・帳票作業を話し合う

**時間: 5 分**

::: info グループワーク
近くの参加者と話し合ってください。  
全部話しきれなくても構いません。気になるテーマから話し始めてください。
:::

**テーマ 1：どんな帳票をよく作っていますか？**

| 帳票の種類 | 場面の例 |
|---|---|
| 見積書 | クライアントに費用感を提示する |
| 請求書 | 納品後に代金を請求する |
| 領収書 | 代金を受領したことを証明する |
| 経費精算書 | 立替払いを会社に申請する |

**テーマ 2：帳票はどのソフト・ツールで作っていますか？**

| ツールの例 | 特徴 |
|---|---|
| Excel / Google スプレッドシート | テンプレートを自分で管理する |
| マネーフォワード クラウド請求書 | 会計データと連動・クラウド管理 |
| freee（フリー） | 確定申告・会計処理も一体で行える |
| 弥生会計 / やよいの青色申告 | デスクトップ型・インストール型 |
| 手書き・Word | 少数の取引のみ |

**テーマ 3：帳票作成のどこに時間や手間がかかっていますか？**

```
（例）
・毎回同じ会社情報を入力し直している
・請求書番号を手で採番していて、重複がないか不安
・見積書から請求書への転記でミスが起きることがある
・マネーフォワードに手でデータを入力するのが面倒
・税率の確認（10%か軽減税率 8%か）に毎回迷う
```

## 3.15. 自分の会計処理フローを書き出す

**時間: 4 分**

以下の質問に答えながら、自分が帳票を作るときの流れを書き出してください。

### 質問 1：どんな帳票をどのくらいの頻度で作っていますか？

```
（記入例）
・見積書: 月に 5〜10 件
・請求書: 月に 5〜10 件（見積もりの承認後に発行）
・経費精算: 月 1 回
```

### 質問 2：帳票を作るまでの手順はどうなっていますか？

「取引の内容が決まってから」「相手に渡すまで」の手順を書いてください。

### 質問 3：現在使っている会計ソフトはどれですか？

以下のどれに当てはまるか確認してください。

- [ ] Excel / Google スプレッドシートで自己管理している
- [ ] マネーフォワード クラウドを使っている
- [ ] freee（フリー）を使っている
- [ ] 弥生会計 / やよいの青色申告を使っている
- [ ] その他（　　　　　　　　　　）

::: info この確認が重要な理由
このセッションの後半（3.19.〜3.23.）では、使っている会計ソフトによって設定手順が異なります。  
今のうちに把握しておくと、ハンズオンがスムーズに進みます。
