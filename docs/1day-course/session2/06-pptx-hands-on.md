# PPTX ハンズオン

**所要時間: 約 20 分（手を動かす作業）**

このページはすべて実際に操作する作業です。  
1 ステップずつ確認しながら進めてください。

## 2.19. PPTXスキルをダウンロードする

**① プロジェクトフォルダに移動する**

ターミナルを開き、以下を入力して `Enter` を押してください。

```bash
cd ~/Desktop/claude-code-seminar
```

::: tip 前の手順からターミナルを開きっぱなしにしている場合
引き続きターミナルを開いている場合は、プロジェクトのルートフォルダにいることを確認してください。
:::

**② PPTXスキルをダウンロードする**

```bash
npx degit TaisukeAndo/claude-code-seminar/packages/skills/pptx-creator .claude/skills/pptx-creator
```

**③ ダウンロードを確認する**

```bash
ls .claude/skills/pptx-creator/
```

`SKILL.md` と `scripts/` が表示されれば成功です。

## 2.20. アウトラインファイルを準備する

PPTX スキルは、スライドの内容をあらかじめファイルに書いておくことで出力の品質が上がります。

**① Cursor でファイルを作成する**

1. Cursor を起動する
2. 「File」メニュー →「Open Folder」でプロジェクトフォルダを開く
3. 左側のファイルツリー上で右クリック →「New File」を選択する
4. ファイル名として `slide-outline.md` と入力して `Enter` を押す

**② アウトラインの内容を入力する**

作成したファイルに以下の内容を貼り付けてください。  
自分の発表内容に合わせて変更しても構いません。

```markdown
# プレゼンタイトル: AI 業務効率化の提案

## スライド 1: タイトル
- タイトル: AI 業務効率化の提案
- 発表者名・所属・日付

## スライド 2: 課題提起
- 現状: 定型業務に毎週多くの時間を費やしている
- 問題: 人手不足により対応が遅れるケースが増えている
- 数値で示す: 業務時間の約 40% が繰り返し作業（出典が必要）

## スライド 3: 解決策
- AI 自動化ツールの導入
- 対象業務: メール返信・レポート作成・データ入力
- 導入後のイメージ図（画像が必要）

## スライド 4: 期待できる効果
- 作業時間: 40% 削減
- コスト: 年間 XX 万円の削減
- グラフ: 導入前後の比較（グラフが必要）

## スライド 5: 導入スケジュール
- Phase 1（1 ヶ月目）: 環境構築・テスト
- Phase 2（2〜3 ヶ月目）: 本番運用
- Phase 3（4 ヶ月目〜）: 効果測定・改善

## スライド 6: まとめ
- 3 つの重要メッセージ
- 次のアクション（打ち合わせ日程の提案）
```

::: tip 「画像が必要」「グラフが必要」と書く意味
アウトラインに「画像が必要」「出典が必要」と書いておくと、スキルはその箇所を認識して、ウェブリサーチのサブエージェントに素材の収集を依頼します。
:::

入力が終わったら `Cmd + S`（macOS）または `Ctrl + S`（Windows）で保存してください。

## 2.21. PPTXスキルでスライドを生成する

**① プロジェクトのルートフォルダに移動する**

```bash
cd ~/Desktop/claude-code-seminar
```

**② Claude Code を起動する**

```bash
claude
```

**③ スライドの生成を指示する**

以下を入力して `Enter` を押してください。

```
slide-outline.md をもとに PowerPoint を作成してください。
デザインはシンプルなビジネス向けで、背景は白、強調色は青系にしてください。
```

アウトラインファイルを使わずに直接指示する方法もあります。

```
AI 業務効率化の提案プレゼン資料を PowerPoint で作成してください。
スライド枚数: 6 枚
対象: 中小企業の経営者
テーマ: AI 導入による業務時間の削減
デザイン: 白背景・青系のアクセントカラー・シンプルなビジネス向け
```

生成には 2〜3 分かかります。

**④ 生成されたファイルを確認する**

処理完了後、プロジェクトフォルダ内に `.pptx` ファイルが生成されます。

macOS の場合:
1. Finder でプロジェクトフォルダを開く
2. 生成された `.pptx` ファイルをダブルクリックして開く

Windows の場合:
1. エクスプローラーでプロジェクトフォルダを開く
2. 生成された `.pptx` ファイルをダブルクリックして開く

## 2.22. 品質確認と修正

生成されたスライドを以下の観点で確認してください。

### 確認チェックリスト

**構成の確認**
- [ ] スライドの流れが論理的になっているか
- [ ] 1 枚のスライドに情報を詰め込みすぎていないか
- [ ] タイトルと本文の内容が対応しているか

**デザインの確認**
- [ ] 文字サイズが読みやすいか（本文は 18pt 以上が目安）
- [ ] 色の使い方が統一されているか

**内容の確認**
- [ ] 数値やデータに出典が記載されているか
- [ ] 会社名・商品名の表記が正しいか

### 修正指示の例

```
3 枚目のスライドの文字数が多いです。
箇条書きを 3 点以内に絞り、残りは「詳細は別紙参照」としてください。
```

```
4 枚目のグラフを棒グラフから折れ線グラフに変更してください。
時間の変化を表したいため、折れ線の方が適しています。
```

```
全スライドのフォントを游ゴシックに統一してください。
また、見出しはすべて太字にしてください。
```

## 2.23. SKILL.md を編集してカスタマイズする

スキルを使っていて「毎回同じ設定を指示している」と感じる場合は、`SKILL.md` を編集することでその設定をスキル側に組み込めます。

**SKILL.md の開き方（Cursor）**

1. Cursor でプロジェクトフォルダを開く
2. 左側のファイルツリーで `.claude` フォルダをクリックして展開する
3. `skills` → `pptx-creator` → `SKILL.md` をクリックして開く

**カスタマイズできる主な項目**

SKILL.md の先頭部分（フロントマター）には以下のような設定があります。

```yaml
---
name: pptx-creator
description: PowerPoint プレゼン資料を自動生成する。「スライドを作って」「PPT を作成して」などのリクエストに対してこのスキルを使う。
---
```

`description` の文言を変更することで、自分が使いやすい言葉でスキルを呼び出せるようになります。

```yaml
description: プレゼン資料を自動生成する。「資料を準備して」「クライアント向けの説明スライドを作って」「社内プレゼン作って」などのリクエストに対してこのスキルを使う。
```
