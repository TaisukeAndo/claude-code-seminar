# DOCX ハンズオン

**所要時間: 約 20 分（手を動かす作業）**

このページはすべて実際に操作する作業です。  
1 ステップずつ確認しながら進めてください。

---

## 2.9. エージェントフォルダをダウンロードする

スキルを動かすために必要なサブエージェントのファイルをダウンロードします。  
**この作業はセッション全体で最初に 1 回だけ行います。**

**① ターミナルを開く**

ターミナルとは、文字を入力してパソコンを操作する画面です。  
開き方は [1. 動作環境の確認](/1day-course/setup/01-requirements#ターミナル-コマンド入力画面-とは) を参照してください。

**② プロジェクトのフォルダに移動する**

以下のコマンドを入力して `Enter` を押してください。

```bash
cd ~/Desktop/claude-code-seminar
```

`cd` は「move into directory（フォルダに移動する）」の略です。

::: tip フォルダの場所がわからない場合
Finder（macOS）でフォルダを開いた状態で、フォルダのアイコンをターミナルにドラッグすると、パスが自動的に入力されます。
:::

**③ エージェントフォルダをダウンロードする**

以下のコマンドをコピーして貼り付け、`Enter` を押してください。

```bash
npx degit TaisukeAndo/claude-code-seminar/.claude/agents .claude/agents
```

コマンドの意味:

| 部分 | 意味 |
|---|---|
| `npx` | Node.js に付属するコマンド実行ツール |
| `degit` | GitHub からフォルダをダウンロードするツールの名前 |
| `TaisukeAndo/claude-code-seminar/.claude/agents` | ダウンロード元の GitHub リポジトリ内のパス |
| `.claude/agents` | 保存先のフォルダ名 |

完了すると以下のように表示されます。

```
> cloned TaisukeAndo/claude-code-seminar#HEAD
```

## 2.10. DOCXスキルをダウンロードする

**① DOCXスキルをダウンロードする**

```bash
npx degit TaisukeAndo/claude-code-seminar/packages/skills/docx-creator .claude/skills/docx-creator
```

`.claude/skills` は、Claude Code がスキル（`/コマンド`）を検索するフォルダです。  
ここにフォルダを配置することで、スキルとして自動的に認識されます。

**② ダウンロードされたファイルを確認する**

```bash
ls .claude/skills/docx-creator/
```

`ls` は「list（一覧表示する）」の略です。

以下のファイルが表示されれば成功です。

```
SKILL.md    scripts/
```

| ファイル・フォルダ | 役割 |
|---|---|
| `SKILL.md` | スキルの設定ファイル。トリガー文言や動作の説明が書かれている |
| `scripts/` | 実際の処理を行う Python スクリプトが入っているフォルダ |

## 2.11. DOCXスキルでドキュメントを生成する

**① プロジェクトのルートフォルダに戻る**

```bash
cd ~/Desktop/claude-code-seminar
```

**② Claude Code を起動する**

```bash
claude
```

以下の画面が表示されれば起動成功です。

```
╭───────────────────────────────────────╮
│ ✻ Welcome to Claude Code!             │
╰───────────────────────────────────────╯

> 
```

`>` の右にカーソルが表示されているのが入力待ちの状態です。

**③ ドキュメント生成を指示する**

`>` プロンプトに以下を入力して `Enter` を押してください。

```
新サービス提案の企画書を Word で作成してください。
サービス名: AI業務効率化パッケージ
対象: 中小企業の経営者
内容: 定型業務をAIで自動化するサービスの提案
ページ数: A4 4ページ程度
構成: 課題提起・解決策・費用対効果・導入スケジュール
```

::: tip 自分の業務内容で試してみる
自分が実際に必要としているドキュメントの内容で試すと、出力品質の確認がしやすくなります。  
会社名や具体的な商品名が含まれる場合は、仮の名前に置き換えて使ってください。
:::

生成には 1〜2 分程度かかります。ターミナルに文字が流れている間は待ってください。

**④ 生成されたファイルを確認する**

処理が完了すると、プロジェクトフォルダ内に `.docx` ファイルが生成されます。

macOS の場合:
1. Finder を開く
2. `~/Desktop/claude-code-seminar` フォルダを開く
3. 生成された `.docx` ファイルをダブルクリックして開く

Windows の場合:
1. エクスプローラーを開く
2. デスクトップの `claude-code-seminar` フォルダを開く
3. 生成された `.docx` ファイルをダブルクリックして Word で開く

## 2.12. 品質を確認して修正を指示する

生成されたドキュメントを確認し、修正が必要な箇所があれば Claude Code に指示を出します。

### 修正指示の出し方

修正を指示するときは、**「何が」「どのように」問題で、「どうしてほしいか」を具体的に伝える**ことが重要です。

| 避けるべき表現 | 具体的な表現 |
|---|---|
| 「なんか違う」 | 「2ページ目の課題提起の文章が短いです。300文字以上で詳しく書き直してください」 |
| 「もっとわかりやすくして」 | 「専門用語を減らして、経営者が読んでわかる表現に変えてください」 |
| 「データを入れて」 | 「市場規模の数字として『国内AI市場は2025年に1.2兆円規模』を3ページ目に追加してください」 |
| 「フォーマット直して」 | 「会社名の表記を全て『株式会社〇〇』の形式に統一してください」 |

### 修正指示の例

**構成を変えたい場合:**
```
現在の構成を「ビジョン・課題・解決策・実績・費用・次のステップ」の順番に変更してください。
```

**内容を追加したい場合:**
```
3ページ目に「導入実績」のセクションを追加してください。
内容: 「〇〇業界での導入事例3社、平均40%の工数削減を達成」
```

**表現を調整したい場合:**
```
文体が硬いので、読みやすい表現に変えてください。
「実施する」→「行う」、「利用する」→「使う」のように、平易な言葉に統一してください。
```

## 2.13. よくある失敗パターンと対処法

| 現象 | 考えられる原因 | 対処方法 |
|---|---|---|
| ファイルが生成されない | 依存するライブラリが不足している | 講師に確認してください |
| 生成されたファイルが空 | 指示の情報が少なすぎる | 目的・対象・ページ数・構成を明示して再実行する |
| 英語で出力される | 言語の指定がない | 指示の末尾に「日本語で作成してください」と追記する |
| エラーメッセージが表示される | スキルのダウンロードが不完全 | 2.10. の手順を再度実行する |
| Word で開けない | Word がインストールされていない | LibreOffice（無料）または Google ドキュメントで開く |
