## 2.1. このセッションで目指す完成形

このセッションの終わりに、参加者それぞれが以下の状態に到達していることを目標とします。

### 完成物のイメージ

**DOCX スキル（2.9.〜2.13.）**

Claude Code に「企画書を作って」と指示するだけで、以下のような Word ファイルが自動生成されます。

```
出力例:
────────────────────────────────────────────
  AI 業務効率化パッケージ 提案書
  
  1. 現状の課題と背景
     ・業務時間の 40% が繰り返し作業に費やされている
     ・...
  
  2. 提案内容
     ・...
  
  3. 費用対効果
     ・...
  
  4. 導入スケジュール
     ・Phase1（1ヶ月目）: 環境構築
     ・...
────────────────────────────────────────────
ファイル形式: .docx（Word で開ける）
```

**PPTX スキル（2.19.〜2.23.）**

アウトラインファイルを渡すと、以下のような PowerPoint ファイルが自動生成されます。

```
出力例:
────────────────────────────────────────────
  スライド 1: タイトル
  スライド 2: 課題提起（数値データ付き）
  スライド 3: 解決策（図解付き）
  スライド 4: 期待できる効果（グラフ付き）
  スライド 5: 導入スケジュール
  スライド 6: まとめ
────────────────────────────────────────────
ファイル形式: .pptx（PowerPoint で開ける）
```

### セッション終了時の状態

| 項目 | 達成基準 |
|---|---|
| スキルのインストール | `create-docx` と `create-pptx` が動作している |
| DOCX の自動生成 | 自分の指示で Word ファイルが生成できた |
| PPTX の自動生成 | アウトラインから PowerPoint が生成できた |
| 修正の指示 | 具体的な修正指示を出して内容を改善できた |
| スキルのカスタマイズ | `SKILL.md` を編集してトリガー文言を変更できた |

## 2.2. 普段のドキュメント作成を話し合う

**時間: 5 分**

::: info グループワーク
近くの参加者と 3〜4 人のグループを作り、以下の 4 つのテーマで話し合ってください。  
全部話しきれなくても構いません。気になるテーマから話し始めてください。
:::

**テーマ 1：どんな種類のドキュメントを作っていますか？**

仕事の中でよく作るドキュメントの名前を出し合ってみてください。

| 種類の例 | 主な読み手 |
|---|---|
| 企画書・提案書 | 上司・クライアント |
| 報告書・業務レポート | 上司・チームメンバー |
| 議事録 | 会議参加者・関係者 |
| 手順書・マニュアル | 担当スタッフ |
| 仕様書・設計書 | 開発・制作メンバー |

**テーマ 2：そのドキュメントはどんな構成ですか？**

「必ず入るセクション」「ページ数の目安」「社内テンプレートの有無」などを共有してください。

**テーマ 3：どんなフローで作っていますか？**

「何から始めるか」「どの順番で作業を進めるか」「誰かに確認してもらうか」など、  
普段の作業の流れを話し合ってください。

**テーマ 4：1 つのドキュメントを作るのにどれくらい時間がかかりますか？**

ドキュメントの種類ごとに、作成にかかる時間の目安を共有してください。

::: tip ファシリテーターへのメモ
5 分後に各グループから印象に残った内容を 1〜2 個ずつ発表してもらいます。
:::

## 2.3. 自分のドキュメント作成フローを書き出す

**時間: 5 分**

グループでの話し合いを踏まえて、個人作業です。  
以下の 4 つの質問に答えながら、**自分がドキュメントを作るときの全体像**を書き出してください。

### 質問 1：よく作るドキュメントを 1〜3 種類書き出してください

種類の名前と、それを作る頻度（週1回・月1回など）も一緒に書いてください。

### 質問 2：そのドキュメントはどんな構成ですか？

以下の観点で書き出してください。

- 必ず含まれるセクション・章立て
- ページ数の目安
- 社内テンプレートの有無
- 必ず含める要素（ロゴ・日付・担当者名・承認欄など）

### 質問 3：作成のフローはどうなっていますか？

「何から始めるか」から「完成・提出するまで」の手順を順番に書いてください。

### 質問 4：ドキュメント作成にかかる時間の内訳は？

1 つのドキュメントを完成させるまでに、どの工程にどれくらい時間がかかるかを書いてください。

```
（記入例）
・情報収集・ヒアリング内容の整理: 30分
・構成を考える（章立て・見出し決め）: 20分
・本文を書く: 60分
・図表・画像の作成・収集: 30分
・レビュー・修正対応: 30分
・合計: 約2〜3時間
```
