## 1. イントロ ― 今回のゴール

### このセクションで学ぶこと
- 今日の勉強会が「何を目指すのか」「何を目指さないのか」
- 全体の地図（今日たどる道すじ）

### なぜこの勉強会をやるのか

みなさんはおそらく、ChatGPT や Claude を毎日のように使い、プロンプト（AIへの指示文）を書くことには慣れています。一方で、「Claude Code」を触ってみたものの、**裏で何が起きているのかが分からない状態**になっている、という方が多いはずです。

今日は、その箱を開けて中の部品に名前をつけていきます。部品の名前と役割さえ頭に入っていれば、実践セッションで手を動かすときに「これはあの部品か」とつながります。

### 今日たどる道すじ（全体の地図）

今日は、**みなさんが既に知っていることを起点に**、順番に積み上げていきます。

```
① プロンプトエンジニアリング（みなさんが既にやっていること）
        ↓ その媒体のひとつが
② Claude（LLMとして選ぶ理由）
        ↓ Claudeに「作業する能力」を持たせたものが
③ Claude Code（ファイル操作・自律実行が可能に）
        ↓ 能力が増えるとリスクも生まれる
   【2つのストーリーが始まる】
        │
        ├─ 🔒 リスクと対策のストーリー
        │      できることが増えた分、意図しない操作や
        │      外部からの攻撃（プロンプトインジェクション）が起きる
        │      → パーミッション・フック・サンドボックスで防ぐ
        │
        └─ 🛠 準備のストーリー
               実践セッションでスムーズに手を動かすために
               「Claude Code をどう設計するか」を学ぶ
               → CLAUDE.md・ルールズ・スキルズ・
                 エージェント・サブエージェント・MCP
```

> この地図は何度も戻ってきます。「今どこを話しているか」を見失ったら、ここに戻ってください。

### このセクションで学んだこと・次のセクションにつながること
- 今日のゴールは「概念を頭に入れること」。完璧な説明は不要
- 起点は「みなさんが既にやっているプロンプトエンジニアリング」
- 次は、まず講師の自己紹介から始めます
