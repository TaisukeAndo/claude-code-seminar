## 全体のまとめ

今日たどった道すじを、2つのストーリーで振り返ります。

```
【起点】プロンプトエンジニアリング（みなさんが既にやっていたこと）
   ↓ その媒体のひとつ
Claude（日本語◎・誤情報少・長文◎）
   ↓ Claudeに「作業する能力」を持たせたもの
Claude Code（ファイル操作・コマンド実行・外部接続が可能な自律型エージェント）
   ↓ 能力が増えた分
【2つのストーリー】
   ↓
 リスクと対策
   意図しない操作 → パーミッションで防ぐ
   AIの不確実な遵守 → フックで確実に実行
   プロンプトインジェクション → パーミッション＋権限の最小化

🛠 設計と準備（コンテキストエンジニアリング）
   「限られた机をどう使うか」の設計
   CLAUDE.md（永続的な指示書）
   ルールズ（CLAUDE.mdの分割管理）
   スキルズ（必要なときだけ読む手順書）
   サブエージェント（仕事を分担して机を守る）
   MCPサーバー（外部サービスへの標準接続口）
```

| 今日のキーメッセージ |
|----------------------|
| Claude Code は「できることが大幅に増えた」。だからこそリスクも増えた |
| そのリスクを抑えながら力を引き出すのが「コンテキストエンジニアリング」 |
| 7つの道具は、それぞれが「特定の問題の解決策」として存在している |

**次の実践セッションで「これはあの部品の話だ」と思えれば、今日の目標は達成です。**

わからないことが出てきたら、アイスブレイクで顔を合わせたチームメンバーや講師に、遠慮なく質問してください。

### 付録：今日の用語ミニ辞典

| 用語 | 一言定義 |
|------|----------|
| Claude | Anthropic製の対話型生成AI。LLMのひとつ |
| Claude Code | Claudeにファイル操作・コマンド実行を持たせた自律型エージェント（CLI） |
| ハルシネーション | AIが誤情報を自信満々に出力する現象 |
| アーティファクト機能 | Web版Claudeで生成物を専用画面でプレビュー・編集できる機能 |
| MCP（Model Context Protocol） | AIと外部サービスをつなぐ共通の接続規格 |
| MCPサーバー | MCPに対応した外部サービスへの接続口 |
| エージェント | 目標を渡すと自律的に動くAIの動作様式（Claude Code本体） |
| サブエージェント | メインから呼び出される、独立した机を持つ専門の助っ人 |
| フック | 決まったタイミングで必ず自動実行される仕掛け |
| ルールズ | 守るべき規則をテーマ別に整理したファイル群 |
| パーミッション | やってよい/だめの範囲を制御する設定 |
| スキルズ | 必要なときだけ読み込む、再利用可能な手順書 |
| コンテキストウィンドウ | AIが一度に覚えられる情報量の上限（机の広さ） |
| コンテキストエンジニアリング | 限られたコンテキストをどう使うか設計する技術 |
| CLAUDE.md | 起動ごとに自動で読まれる永続的な指示書 |
| プロンプトインジェクション攻撃 | 悪意ある指示を外部データに紛れ込ませてAIを操作する攻撃 |
