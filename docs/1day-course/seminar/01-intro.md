# オープニング・Claude Code とは

## Claude Code の概要

Claude Code は Anthropic が開発した AI コーディングアシスタントです。  
ターミナルから直接操作でき、コードの記述・読解・リファクタリング・デバッグを自然言語で指示できます。

## できること

- **コード生成**: 仕様を伝えるだけでコードを書いてくれる
- **コード説明**: 既存コードの意味を説明してくれる
- **バグ修正**: エラーメッセージを渡すと原因と修正方法を提案
- **ファイル操作**: ファイルの作成・編集・削除を指示できる
- **コマンド実行**: Bash コマンドも実行できる
