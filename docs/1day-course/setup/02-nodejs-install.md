# 2. Node.js インストール

Claude Code CLI の実行には **Node.js** というソフトウェアが必要です。

## Node.js とは？

Node.js は、**JavaScript というプログラミング言語をパソコン上で動かすためのソフトウェア**です。

Claude Code は内部的に JavaScript で作られており、Node.js がないと動作しません。  
「ランタイム（実行環境）」とも呼ばれます。難しく考えず、「Claude Code を動かすために必要なソフト」と覚えておけばOKです。

---

## インストール前の確認

まず、Node.js がすでにインストールされているか確認します。

**ターミナル（PowerShell）を開いて**、以下のコマンドを入力し `Enter` を押してください:

```bash
node --version
```

**コマンドの意味:**  
`node` = Node.js に対して、`--version` = 「バージョンを教えて」という意味です。

| 表示された内容 | 対応 |
|---|---|
| `v18.x.x` 以上の数字が表示された | インストール済み → [3. テキストエディタ](/1day-course/setup/03-editor) へ |
| `command not found` または `見つかりません` | インストールが必要 → 下記の手順へ |
| `v16.x.x` 以下の古いバージョン | 更新が必要 → 下記の手順へ |

---

## インストール手順 — macOS

### ① ダウンロードページを開く

1. ブラウザ（Safari / Chrome など）で **[https://nodejs.org/](https://nodejs.org/)** を開く
2. 緑色の **「LTS 推奨版」** ボタン（「20.x.x LTS」などと書かれたもの）をクリック

::: info LTS とは？
「Long Term Support（長期サポート版）」の略で、安定していて長く使えるバージョンです。  
特別な理由がない限り、LTS を選んでください。
:::

### ② ダウンロードしたファイルを実行する

1. ダウンロードが完了したら、**「Finder」** の **「ダウンロード」** フォルダを開く
2. **`node-v20.x.x.pkg`** というファイルをダブルクリック
3. 「このパッケージはソフトウェアをインストールするプログラムを実行します」と表示されたら **「続ける」** をクリック

### ③ インストーラーの手順を進める

以下の画面が順番に表示されます。すべて **「続ける」** または **「インストール」** をクリックして進めてください:

1. **「はじめに」** → 「続ける」
2. **「ソフトウェア使用許諾契約」** → 「続ける」→ 「同意する」
3. **「インストール先の選択」** → そのまま「続ける」
4. **「インストールの種類」** → 「インストール」をクリック
5. パスワードを求められたら **Mac のログインパスワード**を入力して「ソフトウェアをインストール」をクリック
6. **「インストールが完了しました」** と表示されたら「閉じる」

## インストール手順 — Windows

### ① ダウンロードページを開く

1. ブラウザ（Edge / Chrome など）で **[https://nodejs.org/](https://nodejs.org/)** を開く
2. 緑色の **「LTS 推奨版」** ボタン（「20.x.x LTS」などと書かれたもの）をクリック
3. **`.msi`** と書かれたファイルがダウンロードされます

### ② インストーラーを実行する

1. 画面下部またはダウンロードフォルダに **`node-v20.x.x-x64.msi`** があるので、ダブルクリック
2. 「このアプリがデバイスに変更を加えることを許可しますか？」と表示されたら **「はい」** をクリック

### ③ インストーラーの手順を進める

1. **「Welcome」** 画面 → 「Next」をクリック
2. **「End-User License Agreement」** → チェックボックスにチェック → 「Next」
3. **「Destination Folder」**（インストール先）→ 変更不要、そのまま「Next」
4. **「Custom Setup」** → 変更不要、そのまま「Next」
5. **「Tools for Native Modules」** → 変更不要、そのまま「Next」
6. **「Ready to install」** → 「Install」をクリック
7. 「このアプリがデバイスに変更を加えることを許可しますか？」→ **「はい」**
8. **「Finished」** と表示されたら「Finish」

::: warning インストール後はPowerShellを再起動
インストール完了後、PowerShell（ターミナル）を一度**閉じて開き直して**ください。  
再起動しないとコマンドが認識されない場合があります。
:::

---

## インストールの確認

ターミナル（PowerShell）で以下を実行してください:

```bash
node --version
npm --version
```

以下のようにバージョン番号が表示されれば成功です:

```
v20.x.x       ← Node.js のバージョン
10.x.x        ← npm のバージョン
```

::: info npm とは？
`npm`（Node Package Manager）は、Node.js に付属している「パッケージ管理ツール」です。  
スマートフォンの「App Store」や「Google Play」のように、ソフトウェアをインストール・管理するためのツールです。  
次のステップ以降で使います。
:::
