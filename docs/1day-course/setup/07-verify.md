# 7. 動作確認

すべてのセットアップが完了したら、Claude Code が正しく動作するか確認します。

## バージョン確認

ターミナルで以下を実行してください:

```bash
claude --version
```

**コマンドの意味:**  
`claude` = Claude Code に対して、`--version` = 「バージョン番号を教えて」という意味です。

`1.x.x (claude-code)` のようなバージョン番号が表示されれば、インストールは正常です。

---

## 動作テスト：Claude と会話してみる

### ① Claude Code を起動する

```bash
claude
```

ターミナルに以下のような画面が表示されます:

```
╭───────────────────────────────────────╮
│ ✻ Welcome to Claude Code!             │
│   ...                                 │
╰───────────────────────────────────────╯

> 
```

**`>` マーク**が表示されたら入力待ち状態です。

### ② 日本語で話しかけてみる

以下を入力して `Enter` を押してください:

```
こんにちは！自己紹介してください。
```

Claude からの返答が表示されれば、**セットアップは完全に完了**です！

### ③ 終了する

Claude Code を終了するには、**`Ctrl + C`** を押してください（macOS・Windows 共通）。

::: tip Ctrl + C について
`Ctrl + C` は「現在実行中の処理を中断・終了する」という意味のキーボードショートカットです。  
プログラミングでは非常によく使います。覚えておきましょう。
:::
