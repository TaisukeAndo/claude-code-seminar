# 4. Claude Desktop のインストール

Anthropic 公式のデスクトップアプリ「**Claude Desktop**」をインストールします。

## Claude Desktop とは？

Claude Desktop は、**Anthropic が提供する AI チャットアプリ**です。

ブラウザを開かなくても、デスクトップから直接 Claude と会話できます。  
最近のアップデートにより、**Claude Desktop から Claude Code（コーディング機能）を直接利用できる**ようになりました。セミナーではターミナルからの操作が中心ですが、Claude Desktop でも同様の操作ができます。

---

## インストール手順 — macOS

### ① ダウンロードページを開く

1. ブラウザで **[https://claude.ai/download](https://claude.ai/download)** を開く
2. **「Download for macOS」** ボタンをクリック
3. **`Claude-x.x.x.dmg`** がダウンロードされる

### ② アプリをインストールする

1. ダウンロードした **`.dmg`** ファイルをダブルクリックして開く
2. ウィンドウが開き、**「Claude」** アイコンと **「Applications」** フォルダのアイコンが表示される
3. **「Claude」アイコンを「Applications」フォルダにドラッグ＆ドロップ**する
4. コピーが完了したらウィンドウを閉じる
5. **Finder → アプリケーション → Claude** をダブルクリックして起動
6. 「インターネットからダウンロードされたアプリです」と表示されたら **「開く」** をクリック

---

## インストール手順 — Windows

### ① ダウンロードページを開く

1. ブラウザで **[https://claude.ai/download](https://claude.ai/download)** を開く
2. **「Download for Windows」** ボタンをクリック
3. **`Claude-Setup-x.x.x.exe`** がダウンロードされる

### ② アプリをインストールする

1. ダウンロードした **`.exe`** ファイルをダブルクリックして実行
2. 「このアプリがデバイスに変更を加えることを許可しますか？」→ **「はい」**
3. インストールが自動で進む
4. 完了すると Claude Desktop が自動で起動する

---

## ログイン（サインイン）する

Claude Desktop が起動したら、Claude Pro のアカウントでログインします。

1. **「Continue with Google」** または **「Sign in with email」** をクリック
2. Claude Pro に登録したアカウントでログイン
3. ホーム画面が表示されたらログイン完了

::: info Claude Desktop の Claude Code 機能について
Claude Desktop で Claude Code を使うには、ログイン後の設定画面から有効化が必要な場合があります。  
セミナー当日に詳しく説明しますので、今はインストールとログインだけ済ませておいてください。
:::

## Claude Desktop でできること（参考）

| 機能 | 説明 |
|---|---|
| AI チャット | テキストで Claude と会話 |
| ファイルのアップロード | 画像や文書を送って分析・要約 |
| Claude Code | コードの作成・編集をターミナルなしで操作 |
| プロジェクト管理 | 継続的な会話コンテキストの保持 |
