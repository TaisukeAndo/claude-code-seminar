# 3. テキストエディタのインストール

コードを書いたり確認したりするためのアプリ「**テキストエディタ**」をインストールします。

## テキストエディタとは？

テキストエディタは、**プログラムのコードを書くための専用アプリ**です。

Word や Pages のような文書作成ソフトとは異なり、プログラミングに特化した機能（色付き表示・自動補完など）を備えています。Claude Code と組み合わせて使うことで、AI が書いたコードをすぐに確認・編集できます。

---

## おすすめのエディタ

### Cursor（AI 機能に強い・推奨）

Cursor は、**AI アシスト機能を内蔵したテキストエディタ**です。  
Claude Code との相性が良く、エディタ上でコードの説明や修正を AI に頼めます。

**インストール手順 — macOS**

1. ブラウザで **[https://www.cursor.com/](https://www.cursor.com/)** を開く
2. 画面中央の **「Download for Mac」** ボタンをクリック
3. **`Cursor-x.x.x-arm64-mac.dmg`** または **`Cursor-x.x.x-mac.dmg`** がダウンロードされる
4. ダウンロードしたファイルをダブルクリックして開く
5. 開いたウィンドウの **「Cursor」アイコンを「Applications」フォルダにドラッグ**する
6. Finder の「アプリケーション」から「Cursor」をダブルクリックして起動
7. 「インターネットからダウンロードされたアプリです」と表示されたら **「開く」** をクリック

**インストール手順 — Windows**

1. ブラウザで **[https://www.cursor.com/](https://www.cursor.com/)** を開く
2. 画面中央の **「Download for Windows」** ボタンをクリック
3. **`CursorSetup-x.x.x.exe`** がダウンロードされる
4. ダウンロードしたファイルをダブルクリックして実行
5. 「このアプリがデバイスに変更を加えることを許可しますか？」→ **「はい」**
6. インストールが自動で進み、完了するとCursorが起動する

---

### Visual Studio Code（VS Code）

VS Code は、Microsoft が開発した**世界で最も広く使われているテキストエディタ**です。  
豊富な拡張機能があり、Claude Code の IDE 統合にも対応しています。

**インストール手順 — macOS**

1. ブラウザで **[https://code.visualstudio.com/](https://code.visualstudio.com/)** を開く
2. 青い **「Download Mac Universal」** ボタンをクリック
3. **`VSCode-darwin-universal.zip`** がダウンロードされる
4. ダウンロードフォルダの zip ファイルをダブルクリックして展開
5. 展開された **「Visual Studio Code.app」** を **「アプリケーション」** フォルダに移動する

   ::: tip アプリケーションフォルダへの移動方法
   Finder を開いて「ダウンロード」フォルダにある「Visual Studio Code.app」を右クリック →  
   「コピー」→「アプリケーション」フォルダを開いて「ペースト」してください。
   :::

6. 「アプリケーション」から「Visual Studio Code」をダブルクリックして起動
7. 「インターネットからダウンロードされたアプリです」と表示されたら **「開く」** をクリック

**インストール手順 — Windows**

1. ブラウザで **[https://code.visualstudio.com/](https://code.visualstudio.com/)** を開く
2. 青い **「Download for Windows」** ボタンをクリック
3. **`VSCodeSetup-x64-x.x.x.exe`** がダウンロードされる
4. ダウンロードしたファイルをダブルクリックして実行
5. 使用許諾契約 → 「同意する」にチェック → 「次へ」
6. インストール先フォルダ → 変更不要、「次へ」
7. 「デスクトップ上にアイコンを作成する」にチェックを入れると便利
8. 「インストール」をクリック → 完了したら「完了」

::: tip VS Code で Claude Code を使う
VS Code のマーケットプレイスで **「Claude Code」** と検索すると拡張機能をインストールできます。  
これにより、VS Code の画面内から Claude Code を操作できるようになります（セミナー当日に紹介します）。
:::
