# 1. 動作環境の確認

セミナーで使用する Claude Code の動作に必要な環境を確認します。

## 対応 OS

| OS | 対応バージョン |
|---|---|
| macOS | 12 Monterey 以降 |
| Windows | Windows 10 / 11（64bit） |

::: tip お使いの OS のバージョンを確認する方法

**macOS の場合**  
画面左上の「🍎（Apple マーク）」をクリック → 「この Mac について」をクリック  
「macOS Ventura 13.x」などのバージョンが表示されます。

**Windows の場合**  
「スタートボタン（Windowsロゴ）」を右クリック → 「システム」をクリック  
「Windows の仕様」の項目にバージョンが表示されます。
:::

## 必要スペック

| 項目 | 最低要件 |
|---|---|
| メモリ（RAM） | 4GB 以上 |
| ストレージの空き容量 | 1GB 以上 |
| ネットワーク | インターネット接続必須 |

## ターミナル（コマンド入力画面）とは

このセットアップでは「**ターミナル**」または「**コマンドプロンプト**」と呼ばれる画面を使います。

### ターミナルって何？

ターミナルは、**文字（テキスト）でコンピュータに命令を出すためのアプリ**です。

普段はアイコンをクリックしてパソコンを操作しますが、ターミナルではキーボードで「コマンド（命令文）」を入力することで、ソフトウェアのインストールや設定を行います。

最初は少し戸惑うかもしれませんが、このガイドではコピー＆ペーストできるコマンドを用意しています。難しい入力は必要ありません。

### ターミナルの開き方 — macOS

**方法①：Spotlight 検索（推奨）**

1. キーボードの **`⌘ Command`（⌘マーク）+ `スペース`** を同時に押す
2. 画面中央に検索バーが表示される
3. **「terminal」** と入力する
4. 一覧に「ターミナル」が表示されたら **`Enter`** を押す

**方法②：Finder から開く**

1. 画面下の Dock（アプリが並んでいるバー）にある **「Finder」（青い顔のアイコン）** をクリック
2. 左サイドバーの **「アプリケーション」** をクリック
3. **「ユーティリティ」** フォルダをダブルクリックして開く
4. **「ターミナル」** をダブルクリック

**開いたら…**

黒または白い画面に以下のような文字が表示されます。これが「プロンプト」といい、命令の入力待ち状態を意味します:

```
yourname@MacBook-Pro ~ %
```

この状態になれば準備OKです。

---

### ターミナルの開き方 — Windows

**方法①：スタートメニューから検索（推奨）**

1. 画面左下の **「スタートボタン（Windowsロゴ ⊞）」** をクリック
2. そのまま **「powershell」** とキーボードで入力する（検索窓が自動で開きます）
3. 検索結果に **「Windows PowerShell」** が表示されたらクリック

**方法②：右クリックメニューから（Windows 11）**

1. キーボードの **`⊞ Windows` + `X`** を同時に押す
2. 表示されたメニューから **「ターミナル」** または **「Windows PowerShell」** をクリック

**開いたら…**

青い背景の画面に以下のような文字が表示されます:

```
PS C:\Users\あなたのユーザー名>
```

この状態が命令の入力待ち状態です。これで準備OKです。

---

### コマンドの入力方法

ターミナルが開いたら、以下の手順でコマンドを入力します:

1. ターミナルのウィンドウ内をクリックしてアクティブにする
2. コマンドをキーボードで入力（またはコピー＆ペースト）する
3. **`Enter`** キーを押して実行する

::: tip コピー＆ペーストのショートカット
- **macOS**: `⌘ Command + C` でコピー、`⌘ Command + V` でペースト
- **Windows**: `Ctrl + C` でコピー、`Ctrl + V` でペースト

コードブロック（灰色の枠）右上のアイコンをクリックすると、コマンドを一発でコピーできます。
:::

## インターネット接続の確認

Claude Code は Anthropic のサービスに接続するため、**インターネット接続が必須**です。  
セミナー会場の Wi-Fi に接続できるか、事前に確認しておいてください。
